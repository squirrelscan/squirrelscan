- New rule `ax/webmcp` (squirrelscan/repo#396): reports declarative WebMCP tools, the `<form toolname tooldescription>` declarations a browsing agent can call, and flags invalid ones (an empty or malformed `toolname`, a missing `tooldescription`, duplicate names, `toolname` on a non-form, named-parameter problems). It also lists forms that are not tools, notes inline `navigator.modelContext` registration (detected, not validated) and notes a visible CAPTCHA widget on a tool form, recommending an invisible or agent-tolerant check while keeping the protection `security/form-captcha` asks for. It is informational and never lowers the score; the accessibility and layout-shift checks stay in the existing `a11y/*` and `perf/cls-hints` rules, which it links to. See [ax/webmcp](https://docs.squirrelscan.com/rules/ax/webmcp). That makes 343 rules.
