- `install.sh` now provides `openssl` on Alpine/musl (as root, with `apk`, next to `libstdc++`), so signed releases install on a bare Alpine image. On other Linux systems without `openssl` or a logged-in `gh`, the signed-release error names the fix (`apt-get install -y openssl`, `dnf install openssl` or `apk add openssl`, the line for your distro first). It never runs a package manager for you outside Alpine.
