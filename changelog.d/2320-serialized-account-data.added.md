- `security/serialized-account-data` is a new rule that finds account records serialised into framework data (`__NEXT_DATA__`, `__NUXT__`, Qwik state, Astro island props): password hashes, plaintext passwords, API keys, one-time codes and session references. Each finding names the JSON field path and the kind of value, and never prints the value. The fix it gives is to serialise an explicit list of public fields and purge cached copies of the page, not only to rotate keys (#2320)
