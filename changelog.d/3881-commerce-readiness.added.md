- New rule `ax/commerce-readiness`: on sites detected as ecommerce or marketplace, checks each product page's offer for price, currency, availability, shipping details, a return policy and a product identifier, and notes linked product feeds and agent checkout manifests (detected only, never scored). Other site types get one skipped check. Force it on or off with `[rule_options."ax/commerce-readiness"] applies = "on" | "off"`, or the `commerce` argument of the `audit_website` MCP tool. A page that was not read completely is not judged, so a finding from an earlier audit stays open. See [ax/commerce-readiness](https://docs.squirrelscan.com/rules/ax/commerce-readiness).
