- White-label report branding takes an optional `brandColor` (`#rrggbb`) (squirrelscan/repo#3130). It applies only to white-label reports. The HTML report accents its header and `.md`/`.json` links with it, using black or white text, whichever contrasts more. It applies only when that text reaches 4.5:1 on the colour and the colour reaches 3:1 against white; otherwise the default theme is unchanged. The XML root gets a `brand-color` attribute; Markdown and text are unchanged. `@squirrelscan/core-contracts` exports `validateBrandColor`, `pickTextOn` and `contrastRatio`.
