- `a11y/rendered-layout`, a cloud rule for rendered reflow, text spacing and text resize (WCAG 1.4.10, 1.4.12, 1.4.4). It reads layout measurements the `render` service takes in the page's own browser render (no second render): horizontal scrolling at 320px wide, text clipped under the text-spacing overrides, and content clipped at 200% text size, each naming the element selector and the measured width or clipped pixels. Offline, or when the render carries no measurements, it reports a skip with the reason. `RenderResultItem` gains an optional `layout` field. See [a11y/rendered-layout](https://docs.squirrelscan.com/rules/a11y/rendered-layout) (squirrelscan/repo#3091).
