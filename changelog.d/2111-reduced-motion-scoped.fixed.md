- a11y/reduced-motion counts a reduced-motion rule as handling only for the selectors it covers, or for the whole page when it is a global reset (`*`, `html`, `body`, `:root`), so a library stylesheet such as Font Awesome 6 no longer hides a page's own motion; a motion library's own reduce rule (`[data-aos]`, `.animate__animated`, `.animated`) still handles that library. Matching is by element, not selector text, so Tailwind's `motion-reduce:animate-none` on an `animate-spin` element and animate.css infinite animations covered by the library's reduce rule no longer warn, and a reduce rule for `.Spin` no longer clears `.spin` (#2111)
