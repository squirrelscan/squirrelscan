- `squirrel audit --content-store <path>` uses that file as the page-body store for the run, the same as `SQUIRREL_CONTENT_STORE_PATH`. The default store is shared by every project, so point it at a new path for a cold run. When bodies were already in the store, the console output says how many (the report formats do not carry the counts). See [squirrel audit](https://docs.squirrelscan.com/cli/audit).
