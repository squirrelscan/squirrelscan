- Developers: a shared main-text extractor (squirrelscan/repo#2359). `extractMainText(doc, { place })` in `@squirrelscan/parser` turns a parsed page into `{ text, markdown, proseText, blocks[] }`: headings, paragraphs, lists, tables, quotes and code as markdown, each block labelled with the region and section it sat in and the classifier node that said so. With a placer (`extractPageMainText` in `@squirrelscan/page-classifier` wires in the page classifier) it keeps `main_content` and `content_block` regions and drops headers, navigation, footers, sidebars, dialogs, search, forms and article chrome, plus ad, cookie consent, chat widget, newsletter signup, social share and promo banner sections; where the classifier abstains, landmarks and conservative class and id tokens decide. Code blocks are marked and left out of `proseText`. It is not a rule and nothing calls it yet, so no rule output changes (`getMainContent` is untouched). `bun apps/cli/scripts/bench-main-text.ts` scores it against a gold set (`--gold <dir>` for your own) and reports the time it adds.
