- New cloud-only rule `reliability/js-errors`: reports uncaught JavaScript exceptions, framework hydration mismatches, first-party `console.error` messages and runtime requests that fail after load (5xx or 404), as seen by the cloud render. Findings are grouped across the site by message and source file with the page count. 401 and 403 from the site's own API, requests the renderer blocks or aborts, `ResizeObserver loop` messages, CSP violations and WAF challenge pages are not reported. A local or `--http` audit lists it among the cloud checks that did not run. It reads the new optional `runtime` block on a render result, which the renderer fills in (#425). (#704)
