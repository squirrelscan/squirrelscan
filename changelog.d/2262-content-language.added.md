- Rules can read the language a page is actually written in. `ctx.contentLanguage` gives `{ lang, confidence }` for the main content and for each block, from the MIT-licensed franc trigram detector behind a `LanguageDetector` interface. It abstains (null) on short or low-confidence text, and runs only when a rule asks. No rule reads it yet, and the abstention floor is a placeholder until the corpus benchmark (`benchmarks/harness/content-language.ts`) has run. (#2262)
