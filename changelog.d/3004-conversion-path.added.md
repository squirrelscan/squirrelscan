- New rule `content/conversion-path`: warns when a pricing, service or product page has prominent call-to-action buttons that all leave the site for a social profile and the page has no form, `mailto:` or `tel:` link, or link to a contact, booking or checkout page. When the only way to convert is an off-site booking or checkout tool such as Calendly or Stripe Checkout, it reports info. Money pages are found from the URL path and `Product`, `Offer` or `Service` schema; blog posts and documentation are never judged. A page that was not read completely and showed no call to action is not judged, so a finding from an earlier audit stays open. See [content/conversion-path](https://docs.squirrelscan.com/rules/content/conversion-path). (squirrelscan/repo#3004)
