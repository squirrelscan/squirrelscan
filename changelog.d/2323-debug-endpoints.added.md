- New rule `security/debug-endpoints`: on an `active` or `aggressive` probe run, sends one anonymous `GET` each to a short list of debug, config, env, metrics and health paths (`/api/debug`, `/api/config`, `/api/env`, `/metrics`, `/healthz` and others) plus up to five matching same-origin endpoints found in your pages and scripts, and flags each answer that discloses environment variables, configuration secrets, internal hosts, Prometheus metrics or Go expvar state. A bare `{"status":"ok"}` health check is not a finding, and the finding names the endpoint and the class of data, never a value (#2323)
