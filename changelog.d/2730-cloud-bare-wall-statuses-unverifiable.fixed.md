- A link the cloud link checker answers with a bare 401, 406 or 999 is listed as unverifiable in `waf-blocked-external-links`, with `meta.unverifiedReason` `blocked`, instead of warning as possibly broken. The answer is no longer written to the link cache, and late-bound link verdicts carry the same answer. A bare 403 or 405 from the cloud checker's final browser check is kept as sent (squirrelscan/repo#2730).
