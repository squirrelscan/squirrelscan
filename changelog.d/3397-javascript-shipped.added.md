- A JavaScript shipped line in every report format. It gives the script bytes the audit measured, the framework runtime's share when one is recognised by its chunk path (Next.js, Nuxt, Astro or SvelteKit), the third-party share, the scripts not measured, and the three pages that load the most script. The JSON report has a top-level `javascript` object (schema 1.28), and the LLM and XML reports a `<javascript>` element. The line is left out when no script was measured, never affects the score, and survives a later `squirrel report`. See [JavaScript shipped](https://docs.squirrelscan.com/reports#javascript-shipped) (squirrelscan/repo#3397).
