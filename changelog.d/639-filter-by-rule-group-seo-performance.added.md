- Filter by rule group (`seo`, `performance`, `security`, `ai`). `squirrel report --group security` shows only that group's issues; it takes a comma-separated list and combines with `--category`, so an issue must match both. `rules.enable` and `rules.disable` in config, and `--rule-include` and `--rule-exclude`, accept `group:<id>`, which expands to every category in the group (`group:performance` covers `perf/*`). An unknown group is an error that lists the valid ones. See [squirrel report](https://docs.squirrelscan.com/cli/report) and [config](https://docs.squirrelscan.com/cli/config) (squirrelscan/repo#639).
