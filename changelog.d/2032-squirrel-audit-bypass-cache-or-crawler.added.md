- `squirrel audit --bypass-cache` (or `[crawler] no_cache = true`) sends `Cache-Control: no-cache` and `Pragma: no-cache` on page fetches (squirrelscan/squirrelscan#2032), so an audit started right after a deploy makes a CDN revalidate, and revalidates pages cached by an earlier audit with a conditional request instead of reusing them on `max-age` or `stale-while-revalidate`. It is off by default. When it is on, the report lists pages whose response still looks cached (a positive `Age`, or a HIT or STALE `X-Cache`, `CF-Cache-Status` or `X-Vercel-Cache`) as `cacheFreshness` in JSON, and a line in the text and markdown reports. A caller that rendered pages without the render cache can have the report say so with the `freshRender` reconstruct option.
