- New rule `content/color-sprawl`: converts every color literal (hex, `rgb()`, `hsl()`, `oklch()`, named) in `<style>` blocks and `style=` attributes to OKLab and clusters by perceptual distance. It warns when more colors are visually indistinguishable from another than `max_redundant` (default 6), failing at three times that, and warns for a color that only one page uses inline and no linked stylesheet the audit read uses or defines. Literals in `--custom-property` definitions are not counted, so a token-driven design system stays clean. Near-duplicates are counted from inline styles only. Up to 20 same-site linked stylesheets are read (`ctx.site.stylesheets`) to define the palette, so a brand color a stylesheet uses site-wide is not an outlier; every finding says how many stylesheets were read, or that none were. A site with no inline color data is skipped, not passed. A crawl under 10 pages is skipped. Local rule, no account, no credits. The per-page signal joins the site-dom-signals record, so each site's first audit after the upgrade runs fresh once. See [content/color-sprawl](https://docs.squirrelscan.com/rules/content/color-sprawl). (squirrelscan/repo#1377)
