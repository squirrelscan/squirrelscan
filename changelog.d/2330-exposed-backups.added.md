- New rule `security/exposed-backups`: on an aggressive run (`--probe aggressive` or `--pentest`) it requests backup and temporary copies of crawled server-side files (`page.php.bak`, `page.php~`, `.page.php.swp`, `page.php.old`, `page.bak`, `page.php.zip`) and reports each copy the site serves with its URL and inferred content type (PHP, ASP, JSP or ColdFusion source, a script, an archive, a Vim swap file or an SQL dump). Candidates come only from crawled paths on the audited origin, a catch-all `200` is dropped against a random-name check, and the rule sends at most 6 requests per file, 15 files and 120 requests per audit, inside the shared probe budget (#2330)
