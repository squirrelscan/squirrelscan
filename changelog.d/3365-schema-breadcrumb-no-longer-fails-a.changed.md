- `schema/breadcrumb` no longer fails a page because of one link: only a breadcrumb trail named in the markup (an `aria-label`, `class` or `id` containing breadcrumb, outside the site header and footer, and not a page-state class such as `has-breadcrumbs` or a page wrapper) counts, a link the page classifier's model alone placed in the breadcrumbs section never does, and the trail needs at least two links. Because the trail is read from the markup, the check now also runs with `--no-classifier`, and a link in a markup-named trail now carries the `breadcrumbs` section (squirrelscan/repo#3365).
