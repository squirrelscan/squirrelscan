- `squirrel entities` now reads exact per-page figures from the local store. The store records each page's declaration count and references, and whether an audit wrote a map at all, so a page that declares the same entity twice keeps its `entityCount`, and an audit that found no JSON-LD is shown as a completed empty map instead of being passed over for an older audit. Audits stored before this release still read as before. The local store schema is version 47 (two new tables, nothing existing changed). (squirrelscan/repo#2105)
