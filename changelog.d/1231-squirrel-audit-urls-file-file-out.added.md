- `squirrel audit --urls-file <file> --out-dir <dir>` audits a list of URLs in one batch (squirrelscan/repo#1231): one report per URL in `--out-dir`, named by a hash of the URL, plus `results.jsonl` with one line per URL (status, reason, score, pages, exit code, timings). Re-running the same command resumes and skips URLs already done; `--retry-failed` runs the failed ones again and `--restart` starts over. `--concurrency` sets how many audits run at once, `--url-timeout` is a hard time limit per URL in seconds, `--max-urls` caps the list (100000 by default), and `--allow-private-hosts` allows loopback and private hosts, which are refused by default. The batch exits `6` when at least one URL failed, was blocked, unreachable, redirected, timed out, crashed, was rejected or was skipped. Batch mode is local only for now: signed-in batches are refused unless you pass `--offline`. See [Batch audits](https://docs.squirrelscan.com/cli/audit#batch-audits).
