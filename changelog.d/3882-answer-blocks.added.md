- New rule `ax/answer-blocks`, an advisory rule for content pages. It lists question headings (`h2` to `h4` ending in a question mark) with no short, self-contained answer in the first two sentences, and data tables or charts with no source next to them. It is `info` severity, so it never changes the score. The Agents section of the console, text, markdown and HTML reports now carries one line that links to the existing date, author and citation rules (`eeat/content-dates`, `content/freshness`, `content/date-agreement`, `eeat/author-byline`, `eeat/author-expertise`, `eeat/citations`) with their status, without repeating their findings. See [ax/answer-blocks](https://docs.squirrelscan.com/rules/ax/answer-blocks). (squirrelscan/repo#3882)
