- New rule `crawl/home-page-unreachable`: when the audited URL does not load because its DNS did not resolve, the TLS handshake failed, the connection was refused or dropped, the server timed out or it answered 5xx, the audit now reports an error finding with the cause, so a down site shows up in findings and alerts instead of only as a failed run. A 4xx answer, a robots.txt refusal and a bot wall are not reported by this rule. See [crawl/home-page-unreachable](https://docs.squirrelscan.com/rules/crawl/home-page-unreachable).
