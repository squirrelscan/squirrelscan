- `ax/markdown-response` now tells a server error apart from absent Markdown. The probe also requests the homepage with a strict `Accept: text/markdown`, the header a Markdown-only agent sends, because the lenient probe ends in `*/*` and a server can answer it with HTML while it errors on the strict one. A 5xx on the strict request, while the lenient request was answered, is reported as a new `markdown-negotiation-error` failure that counts against the score. When the strict request gets no answer (refused, throttled, timed out or out of probe budget), the check is skipped as not checked with the coded reason `strict-probe-unanswered`, so an earlier finding stays open instead of reading as fixed. A site that simply does not serve Markdown still gets the score-neutral recommendation, and an `/index.md` that never answered is reported as not checked, not absent. (squirrelscan/repo#1322)
