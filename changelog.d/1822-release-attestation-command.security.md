- Release binaries are only built from `main`, so their attestation always names the release workflow on main. To check a download yourself, run `gh attestation verify ./squirrel-<version>-<platform> --repo squirrelscan/squirrelscan --cert-identity https://github.com/squirrelscan/squirrelscan/.github/workflows/release.yml@refs/heads/main --deny-self-hosted-runners` (see Verifying a release in the install docs). This replaces the shorter command in the v0.0.181 notes. (#1822)
