- `install.sh` and `squirrel self update` accept a release signed by a pinned squirrelscan release key (ECDSA P-256, checked with `openssl` and WebCrypto) as well as one with a GitHub build attestation. A signature from an unpinned or revoked key, or one that does not verify, stops the install even if an attestation would pass. No key is pinned yet, so nothing changes until one is ([docs](https://docs.squirrelscan.com/install#verifying-a-release)) (squirrelscan/repo#5032)
