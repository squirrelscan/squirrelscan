## 1. Set it up

Pick one. Both end with the `squirrel` CLI installed and a first audit run.

### With your coding agent

Copy one line into Claude Code, Codex, Cursor, opencode or any other coding
agent. It installs the CLI, adds the squirrelscan skill and MCP, and runs a
first audit of your site.

### Yourself

<div class="sq-install">
<CodeGroup>

```bash macOS / Linux
curl -fsSL https://install.squirrelscan.com | bash
```

```powershell Windows
iwr -useb https://install.squirrelscan.com/install.ps1 | iex
```

```bash Homebrew
brew install --cask squirrelscan/tap/squirrel
```

```bash npm
npm install -g squirrelscan
```

</CodeGroup>
</div>

Then run setup once: it signs you in (optional), installs the agent skills and
turns on auto-update.

```bash
squirrel setup
```

[Install](/install) covers install options, PATH, verifying a release,
networks that block GitHub, and uninstalling.

## Common options

<Steps>
  <Step title="Limit pages crawled">
    For large sites, limit pages to get faster results:
    ```bash
    squirrel audit https://nutshop.squirrelscan.com -m 10
    ```
  </Step>

  <Step title="Export to JSON">
    Output machine-readable JSON for CI/CD or AI processing:
    ```bash
    squirrel audit https://nutshop.squirrelscan.com -f json -o report.json
    ```
  </Step>

  <Step title="Generate HTML report">
    Create a visual HTML report:
    ```bash
    squirrel audit https://nutshop.squirrelscan.com -f html -o report.html
    ```
  </Step>

  <Step title="Fresh crawl">
    Ignore cache and fetch all pages fresh:
    ```bash
    squirrel audit https://nutshop.squirrelscan.com --refresh
    ```
  </Step>

  <Step title="Choose an audit level">
    Pick depth or speed. `quick` is fast: up to 25 pages, without the cloud checks (logged out it runs locally, no account needed; logged in it is billed like any level, up to 100 credits). `surface` audits one page per template with the cloud checks. `full` reads every page up to 500:
    ```bash
    squirrel audit https://nutshop.squirrelscan.com --level quick
    ```
    The default is `quick` when you're logged out and `surface` when you're logged in. See [Audit levels](/guides/audit-levels) for what each one checks and costs.
  </Step>

  <Step title="Run only some categories">
    Narrow the audit to the categories you care about right now.

    <Warning>A filtered audit produces a partial report. Scores reflect only the rules that ran, so don't compare them against a full audit.</Warning>

    ```bash
    squirrel audit https://nutshop.squirrelscan.com --rule-include ax,perf
    ```
  </Step>
</Steps>

## Output formats

| Format | Flag | Use Case |
|--------|------|----------|
| `console` | (default) | Human-readable terminal output |
| `json` | `-f json` | CI/CD, programmatic processing |
| `html` | `-f html` | Visual reports for sharing |
| `markdown` | `-f markdown` | Documentation, GitHub |
| `text` | `-f text` | Clean output for piping to LLMs |
| `llm` | `-f llm` | LLM optimized output |
| `xml` | `-f xml` | XML output |

<Note>
All seven formats work with both `squirrel audit --format` and `squirrel report --format`.
</Note>
