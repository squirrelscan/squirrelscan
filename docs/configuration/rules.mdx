The `[rules]` section controls which audit rules run during analysis.

## Configuration

```toml
[rules]
enable = ["*"]
disable = ["images/modern-format", "links/orphan-pages"]
```

## Options

### `enable`

**Type:** `string[]`
**Default:** `["*"]` (all default-on rules)

Patterns of rules to enable. Supports wildcards and specific rule IDs.

The default `*` pattern deliberately skips opt-in rules such as `gaps/keywords` and
`gaps/content`. Add an explicit rule or category pattern alongside `*` to run them,
for example `enable = ["*", "gaps/*"]`.

**Pattern Syntax:**

- `*` - All default-on rules (opt-in rules are skipped)
- `category/*` - All rules in a category
- `category/rule-name` - Specific rule

**Examples:**

Enable all rules (default):
```toml
[rules]
enable = ["*"]
```

Enable specific categories:
```toml
[rules]
enable = ["core/*", "links/*", "images/*"]
```

Enable specific rules:
```toml
[rules]
enable = ["core/meta-title", "core/meta-description", "links/broken-links"]
```

---

### `disable`

**Type:** `string[]`
**Default:** `[]` (nothing disabled)

Patterns of rules to disable. **Takes precedence over `enable`**.

If a rule matches both `enable` and `disable`, it's disabled.

**Examples:**

Disable the agent experience rules (`ax/*`; the older `ai/*` code matches the same rules):
```toml
[rules]
disable = ["ax/*"]
```

Disable a whole category:
```toml
[rules]
disable = ["perf/*"]
```

Disable specific rules:
```toml
[rules]
disable = ["content/word-count", "images/modern-format"]
```

### `time_budget_ms`

**Type:** `integer` (milliseconds: `0`, or `1000` or more)
**Default:** unset (2000 ms)

How long one rule may run on one page before it is abandoned and reported as not evaluated on that page (a skipped check, never a failure). A site rule gets this much per page of the site, capped at 60 seconds, or at the budget itself if you set it above that. `0` turns the budget off. A value below 1000 is refused for now: a rule that finishes just past a tight budget can stop the audit ([#880](https://github.com/squirrelscan/squirrelscan/issues/880)).

The budget is a backstop against content built to make a pattern match very slowly, not a performance setting: ordinary pages take a few milliseconds per rule. Raise it if rules time out on ordinary pages on a slow or busy machine. See [Rule time budget](/rules#rule-time-budget) for what a timed-out rule reports.

```toml
[rules]
time_budget_ms = 3000
```

## Rule categories

squirrelscan runs **300+ rules** across **22 categories**. Each category's page lists its rules and what each one checks; the [rules reference](/rules) has the per-category counts.

| Category | Pattern | What it covers |
|----------|---------|----------------|
| [Crawlability](/rules/crawl) | `crawl/*` | Robots.txt, sitemaps, and crawl directives |
| [Core SEO](/rules/core) | `core/*` | Essential meta tags and page structure for search engines |
| [Security](/rules/security) | `security/*` | Transport security, headers, cookies, forms and leaked secrets |
| [Site Integrity](/rules/integrity) | `integrity/*` | Signs of compromise: injected pages, phishing kits, malware, SEO spam |
| [Links](/rules/links) | `links/*` | Internal and external link health and structure |
| [Content](/rules/content) | `content/*` | Text quality, readability, and content structure |
| [Structured Data](/rules/schema) | `schema/*` | Structured data and rich snippet eligibility |
| [Images](/rules/images) | `images/*` | Image optimization and accessibility |
| [Performance](/rules/perf) | `perf/*` | Page speed and loading performance |
| [Reliability](/rules/reliability) | `reliability/*` | Runtime errors, broken resources, failed requests, broken links and broken anchors (those three rules keep their `links/` ids, so `links/*` selects them) |
| [Social Media](/rules/social) | `social/*` | Open Graph and social sharing metadata |
| [Accessibility](/rules/a11y) | `a11y/*` | Accessible names, ARIA, forms, structure, tables, language and zoom |
| [Mobile](/rules/mobile) | `mobile/*` | Mobile-friendliness and responsive design |
| [URL Structure](/rules/url) | `url/*` | URL structure, length, and formatting |
| [Internationalization](/rules/i18n) | `i18n/*` | Language declarations and multi-region support |
| [E-E-A-T](/rules/eeat) | `eeat/*` | Experience, expertise, authority, trust signals |
| [Legal Compliance](/rules/legal) | `legal/*` | Privacy policy and legal compliance signals |
| [Local SEO](/rules/local) | `local/*` | Local business schema and NAP consistency |
| [Video](/rules/video) | `video/*` | Video content markup and accessibility |
| [Analytics](/rules/analytics) | `analytics/*` | Tracking and measurement implementation |
| [Agent Experience](/rules/ax) | `ax/*` | How ready a site is for AI agents to read, discover, and operate on it |
| [Blocking](/rules/adblock) | `blocking/*` | Content, links, and trackers that ad blockers and privacy filters block |

Use the pattern in `enable` or `disable` to switch a whole category on or off. Two categories also answer to an older code: `ai/*` matches the Agent Experience rules (some of their ids still start with `ai/`), and `adblock/*` matches the Blocking rules. A pattern with either code matches the whole category.

Most Agent Experience rules run on your machine on every audit, with no API key. Five read results from squirrelscan's cloud (`ai/site-metadata`, `ai/page-type-match`, `ai/llm-parsability`, `ax/archive-indexing` and `ax/content-without-js`), so they need a signed-in audit whose [level](/guides/audit-levels) includes those cloud checks, and are skipped otherwise. `ax/content-without-js` also needs the plain crawl HTML of the page to compare with its cloud render, so it is skipped on pages the crawl itself rendered.

Keyword and content gap analysis (`gaps/*`) is an opt-in cloud add-on, not one of the 22: see [Keyword and content gaps](/rules/gaps).

## Configuration examples

### SEO-focused audit

Focus on SEO rules only:

```toml
[rules]
enable = ["core/*", "content/*", "crawl/*", "url/*", "schema/*"]
disable = []
```

### Accessibility audit

Focus on accessibility and mobile:

```toml
[rules]
enable = ["a11y/*", "mobile/*"]
disable = []
```

### Performance audit

Focus on performance and images:

```toml
[rules]
enable = ["perf/*", "images/*"]
disable = []
```

### Security audit

Focus on security headers and HTTPS:

```toml
[rules]
enable = ["security/*"]
disable = []
```

### All rules except agent experience

Enable everything except the agent experience rules:

```toml
[rules]
enable = ["*"]
disable = ["ax/*"]
```

### Fast audit (core only)

Quick audit with just essential checks:

```toml
[rules]
enable = ["core/*"]
disable = []
```

### Disable slow rules

Exclude computationally expensive rules:

```toml
[rules]
enable = ["*"]
disable = ["ax/*", "perf/cls-hints"]
```

### CI/CD pipeline

Strict subset for automated checks:

```toml
[rules]
enable = ["core/*", "security/*", "links/broken-links"]
disable = []
```

## Pattern matching

### Wildcards

A `*` is only supported as the whole pattern (`*`) or as the whole rule name (`category/*`). A partial wildcard such as `core/og-*` matches no rule, so list the rules instead:

```toml
[rules]
enable = ["core/*", "social/*"]  # All core and social rules
disable = ["core/og-tags", "social/og-image-size", "social/og-url-match"]  # Except the Open Graph ones
```

### Retired rules

`content/quality` and `ai/ai-content` are retired: they never load, whatever `enable` says, so a `disable` entry for either one does nothing and can be removed.

### Multiple patterns

```toml
[rules]
enable = ["core/*", "links/*", "images/*"]
disable = ["images/modern-format", "links/orphan-pages"]
```

### Disable takes precedence

```toml
[rules]
enable = ["*"]           # Enable all
disable = ["ax/*"]       # But disable agent experience (wins)
```

Result: all rules except the agent experience category.

## Rule weights

Each rule has a weight (1-10) reflecting its importance:

| Weight | Importance | Example Rules |
|--------|------------|---------------|
| 10 | Critical | `core/meta-title`, `crawl/robots-txt` |
| 8 | High | `core/canonical`, `links/broken-links` |
| 6 | Medium | `images/alt-text`, `content/word-count` |
| 4 | Low | `url/hyphens`, `social/share-buttons` |
| 2 | Info | `analytics/gtm-present` |

Weights affect the health score calculation.
