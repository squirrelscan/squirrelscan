The `skills` command installs squirrelscan capabilities into coding agents that support the [Agent Skills](https://agentskills.io/home) standard.

## What are agent skills?

Agent Skills are folders of instructions, scripts, and resources that coding agents can discover and use to perform tasks more accurately. Skills give agents access to procedural knowledge they can load on demand.

The Agent Skills format is an open standard supported by many coding agents including:

- **Claude Code** - Anthropic's CLI coding agent
- **Cursor** - AI-first code editor
- **VS Code** - With GitHub Copilot
- **Gemini CLI** - Google's coding agent
- **OpenAI Codex** - OpenAI's coding agent
- **Goose** - Block's open source agent
- **Amp** - Sourcegraph's coding agent
- **Roo Code** - coding agent

For the full list of supported agents, see [agentskills.io](https://agentskills.io/home).

## The squirrelscan skills

squirrelscan ships these skills from the [squirrelscan/skills repository](https://github.com/squirrelscan/skills), the one source for every install path below:

| Skill | What it does |
|-------|--------------|
| `squirrelscan` | Operate the CLI: install, login, run audits, publish reports, credits, API keys, the entity map, MCP setup, configuration, troubleshooting |
| `audit-website` | The fix loop: audit a site, map findings to code, fix in batches, re-audit until it scores well |

## install

Install the squirrelscan skills for your coding agent.

### Usage

```bash
squirrel skills install
```

### What it does

The command runs `npx skills@1 add squirrelscan/skills -g` to install all the squirrelscan skills from the [squirrelscan/skills repository](https://github.com/squirrelscan/skills). The `@1` pins the skills CLI to the major version squirrel's commands were checked against.

Once installed, you can invoke them in your coding agent:

```text
/audit-website
```

```text
/squirrelscan
```

### Example

```bash
$ squirrel skills install
Installing squirrelscan skills (squirrelscan, audit-website)...

Skills installed! Use /audit-website or /squirrelscan in your agent.
View skills: https://skills.sh/squirrelscan/skills
```

### Without npm/npx

If npm/npx is not available, the command displays manual installation instructions:

```bash
$ squirrel skills install
npx not found. Install Node.js or run manually:

To run manually:
  npx skills@1 add squirrelscan/skills -g

View skills: https://skills.sh/squirrelscan/skills
```

## update

Update the squirrelscan skills to the latest version.

### Usage

```bash
squirrel skills update
```

### What it does

The command reads the skills lock files (global and the current project's) and brings both squirrelscan skills current:

- an install recorded from `squirrelscan/squirrelscan`, where the skills used to ship, is re-added from [squirrelscan/skills](https://github.com/squirrelscan/skills), their only home now
- every other install is refreshed with `npx skills update`, from the repository it was installed from

It never installs a skill you don't already have; with none installed it says so and points you at `squirrel skills install`. A re-added skill lands in the agents the skills CLI detects on your machine, the same as its own update does.

### Automatic updates

You rarely need to run it. From v0.0.99, when squirrel [auto-updates itself](/cli/self#automatic-updates), the first run on the new version starts the same refresh in the background for your global skill installs, with no prompts and a 60 second limit. It runs once per new version, follows the same opt-outs as auto-update (`auto_update`, `SQUIRREL_NO_UPDATE`, CI), does nothing without `npx`, and never holds up the command you ran. Project installs are left to `squirrel skills update`.

### Example

```bash
$ squirrel skills update
Moving squirrelscan from squirrelscan/squirrelscan to squirrelscan/skills...
Updating squirrelscan skills (squirrelscan, audit-website)...

Skills updated!
View skills: https://skills.sh/squirrelscan/skills
```

### Without npm/npx

If npm/npx is not available, the command displays manual update instructions:

```bash
$ squirrel skills update
npx not found. Install Node.js or run manually:

To run manually:
  npx skills@1 update squirrelscan audit-website -y

View skills: https://skills.sh/squirrelscan/skills
```

## Claude Code plugin

Claude Code users can install everything (all skills plus the hosted MCP server) as a plugin instead:

```text
/plugin marketplace add squirrelscan/skills
/plugin install squirrelscan@squirrelscan
```

Every commit to the skills repository is a new plugin version. Claude Code doesn't auto-update third-party marketplaces unless you turn it on in `/plugin`, so pick up new versions with `/plugin marketplace update squirrelscan` and `/plugin update squirrelscan@squirrelscan`.

Added the older `squirrelscan/squirrelscan` marketplace before? It now points the plugin at squirrelscan/skills, so it keeps working: run those same two update commands to move over. To switch marketplaces instead, remove the old one first. Claude Code won't add a second marketplace named `squirrelscan`, and removing it uninstalls the plugin, so reinstall:

```text
/plugin marketplace remove squirrelscan
/plugin marketplace add squirrelscan/skills
/plugin install squirrelscan@squirrelscan
```

## The audit-website skill

The `audit-website` skill gives your coding agent the ability to run comprehensive website audits using squirrelscan and drive the findings to fixed code. When invoked, the agent will:

1. Run `squirrel audit` on the target URL
2. Analyze the results and map issues to your code
3. Propose and apply fixes, then re-audit

### Invoking the skill

In Claude Code or other compatible agents:

```text
/audit-website https://example.com
```

The agent will handle running the audit and interpreting results for you.

## The squirrelscan skill

The `squirrelscan` skill teaches your agent the CLI itself: installation, authentication, publishing reports, cloud credits, API keys, MCP setup, and configuration. Agents load it whenever a task touches squirrelscan beyond a basic audit, for example "publish this report" or "connect squirrelscan over MCP".
