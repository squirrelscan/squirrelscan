The `analyze` command runs audit rules on a previously crawled website without re-crawling.

## Usage

```bash
squirrel analyze [options]
```

## Options

| Option | Description | Default |
|--------|-------------|---------|
| `--id` | Crawl ID to analyze | Latest crawl |

## What it fetches

`analyze` does not crawl again, but some rules read more than the stored pages. Like `squirrel audit`, it fetches the stylesheets, images, fonts, scripts, PDFs and web app manifest the pages reference. It also status-checks the sitemap URLs and the [internal link targets](/configuration/external-links#internal-links) the crawl did not fetch, within the crawl's own scope. While `reliability/broken-resources` is on, it status-checks the third-party scripts, stylesheets and fonts the pages load too. Every request and every redirect it follows is held to the same rules as the audit's, so it never connects to a link-local or cloud metadata address. It sends no custom request headers, and it does not check external links.

To turn the internal link checks off, set `[internal_links] enabled = false`. To turn the third-party checks off, disable `reliability/broken-resources`.

## Examples

### Analyze latest crawl

```bash
squirrel analyze
```

### Analyze specific crawl

```bash
squirrel analyze --id a7b3c2d1
```

## Output

```text
Analyzing latest crawl...

✓ Ran 87 rules in 2.3s

Analysis complete: a7b3c2d1
  Site: https://example.com
  Passed: 52 | Warnings: 18 | Failed: 17

Run 'squirrel report' to view results.
```

## Use cases

### Iterate on rule configuration

```bash
# Crawl once
squirrel crawl https://example.com

# Test different rule configs
squirrel analyze
# Edit squirrel.toml
squirrel analyze
```

### Re-analyze after code changes

```bash
# While developing custom rules
squirrel analyze
```

### Separate crawl and analysis

```bash
# Crawl during off-hours
squirrel crawl https://example.com

# Analyze later
squirrel analyze
```

## Configuration

The analyze command respects rule settings from `squirrel.toml`:

```toml
[rules]
enable = ["*"]
disable = ["ai/*"]

[rule_options]
# Rule-specific options
```

See [Configuration](/configuration) for all options.

## Exit codes

| Code | Meaning |
|------|---------|
| `0` | Success |
| `1` | Error (no crawl found, analysis failed, etc.) |
