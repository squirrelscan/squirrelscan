Links rules read the link graph the crawl built. Half of them are health checks: internal and external targets that return an error, hrefs that do not parse, links that drop to plain HTTP, links that resolve only through a redirect. The other half describe structure: how many links point at a page, whether any of them sit in body copy rather than the footer, and whether the anchor text says what the destination is.

## Run only these rules

```bash
squirrel audit https://example.com --rule-include links
```

[Cloud dead-link checking](/rules/links/dead-links) runs only when you are signed in. Logged out, external links are checked from your machine instead.

## Where to start

These carry the highest severity and weight in the category.

- [Links from an HTTPS page to an http:// destination](/rules/links/https-downgrade): A link that drops the visitor to plain HTTP hands their next request to the network. squirrel flags every explicit http:// link on an HTTPS page.
- [Orphan pages: pages with too few inbound internal links](/rules/links/orphan-pages): A page nothing links to is hard to discover and reads as unimportant. squirrel counts dofollow inbound internal links for every crawled page.
- [rel=nofollow on an internal link: usually a mistake](/rules/links/nofollow-internal): Nofollow on your own links tells search engines to ignore your site's internal structure. squirrel flags every internal link carrying it.
- [Empty and generic anchor text: click here and icons](/rules/links/anchor-text): A link with no text has no name, and click here describes nothing. squirrel groups links by destination and checks each group for a descriptive name.
- [Internal link count per page: too few and too many](/rules/links/internal-links): A page with no internal links leads nowhere and a page with hundreds dilutes each one. squirrel counts internal links against a configurable range.

## Link checking defaults

Internal link checks run at every [audit level](/guides/audit-levels), Quick included, and are free. Each internal link target the crawl did not fetch gets a status-only request (up to 200 per audit, most-linked first), so a linked 404 is found even when the crawl did not follow links or ran out of page budget. It is built not to change anything on your site: it skips links that look like actions (log out, unsubscribe, delete, confirm, add to cart) or carry a token, sends no cookies, credentials or custom headers, and sends `HEAD`, never a `GET` unless the server does not support `HEAD`. See [What the internal link check never requests](/configuration/external-links#what-the-internal-link-check-never-requests).

External link checks run at every level, Quick included. Skip them with `--no-external-links`, `[external_links] enabled = false`, or the website's **External link checks** setting in the cloud. An audit that checks them requests up to its page budget or 200 distinct external links, whichever is more, most-linked first. In a cloud audit, or a signed-in CLI audit at Surface or Full, each external link the cloud verifies costs 1 credit, at most one per page of the audit's budget. Links checked on your machine are free, a Quick CLI audit's included.

| Where | External links | Internal links |
|-------|----------------|----------------|
| One CLI run | `--external-links` to check them, `--no-external-links` to skip them | `--no-internal-links` to skip them |
| `squirrel.toml` | `[external_links] enabled = false` to skip them | `[internal_links] enabled = false` to skip them |
| A cloud website | The website's **External link checks** setting | The website's **Internal link checks** [crawl setting](/dashboard/crawl-settings#internal-link-checks) |

`--offline` skips external links, since it promises no requests beyond the audited site. A check that did not run is reported as **Not checked** with the reason, never as a pass.

## Key terms

- [Anchor text](/glossary/anchor-text): The visible, clickable text of a link, which tells readers and search engines what the target is about.
- [Broken link](/glossary/broken-link): A link whose target answers with an error, does not resolve, or is malformed.
- [Crawl budget](/glossary/crawl-budget): The number of URLs a search engine is willing and able to crawl on a site in a given time, set by crawl capacity and crawl demand.
- [HTTPS](/glossary/https): HTTP over TLS, which encrypts traffic and proves the server's identity; every page and form should use it.
- [Internal linking](/glossary/internal-linking): Links between pages of the same site, which carry crawlers and readers through it and signal which pages matter.
- [Orphan page](/glossary/orphan-page): A page that no other crawled page links to, so crawlers and readers only reach it through a sitemap or a direct URL.
- [Redirect chain](/glossary/redirect-chain): A sequence of two or more redirects between the requested URL and the final response.
- [rel=nofollow](/glossary#nofollow): A link attribute value asking search engines not to associate the linking page with the target; a hint, not a block.
