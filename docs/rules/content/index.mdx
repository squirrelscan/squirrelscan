Content rules read the words a visitor actually sees. Some of them catch pipeline failures that reach the reader as text: mojibake, literal markdown, lorem ipsum, a development URL, a visible undefined. Others measure the writing itself, its length, its readability and its keyword density. A third group compares pages against each other, finding duplicate titles, thin outliers and titles that break the site's own template.

## Run only these rules

```bash
squirrel audit https://example.com --rule-include content
```

[LLM content quality score](/rules/content/quality) is retired and never runs. It stays in the table so its page and ID keep working.

## Where to start

These carry the highest severity and weight in the category.

- [Meta tags in the body: why they are silently ignored](/rules/content/meta-in-body): A meta description or robots tag inside body is not read by anything. squirrel finds every meta element that ended up outside the head.
- [Duplicate title tags: the same title on several pages](/rules/content/duplicate-title): Two pages with the same title compete with each other in search and look identical in results. squirrel groups every crawled page by its title.
- [Hidden text and links: what Google's spam policy covers](/rules/content/hidden-text): Text a crawler reads and a visitor cannot see is a spam policy violation. squirrel finds it while exempting screen-reader and collapsed-UI patterns.
- [localhost in production: dev hosts left in the markup](/rules/content/dev-leakage): A link or image pointing at localhost or a preview deployment is broken for every visitor. squirrel classifies the host and says whether it is yours.
- [Lorem ipsum in production: placeholders and leftovers](/rules/content/placeholder-text): Filler copy, unrendered template syntax and a visible undefined all mean something shipped unfinished. squirrel names the family and shows a sample.

## Key terms

- [Author byline](/glossary#author-byline): The visible author name on an article, ideally linked to an author page and matched by an author entity in structured data.
- [Character encoding](/glossary/character-encoding): The mapping from bytes to characters (normally UTF-8) declared in the Content-Type header or a meta charset tag; a mismatch produces mojibake.
- [Cloaking](/glossary#cloaking): Serving search engines or particular user agents different content from what visitors see, a Google spam policy violation.
- [Content freshness](/glossary/content-freshness): How current a page is and how consistently it says so: visible dates, dateModified, sitemap lastmod and copyright year.
- [Duplicate content](/glossary/duplicate-content): The same or near-identical content reachable at more than one URL, or repeated titles and descriptions across pages.
- [Heading hierarchy](/glossary/heading-hierarchy): The nesting of h1 to h6 headings that gives a page its outline for readers, screen readers and parsers.
- [HTML validity](/glossary#html-validation): Whether the markup parses as intended: closed elements, head-only tags in the head, and no raw markup printed as text.
- [Keyword stuffing](/glossary#keyword-stuffing): Repeating a term far beyond natural use in the hope of ranking for it, which Google lists as spam.
- [Leaked secrets](/glossary/leaked-secrets): Credentials or private keys shipped to the browser in HTML, scripts or source maps.
- [Meta description](/glossary/meta-description): A `<meta name="description">` summary of the page that search engines may use as the result snippet.
- [Placeholder content](/glossary#placeholder-content): Template filler left in production: lorem ipsum text, stock placeholder images, example phone numbers and emails.
- [Readability](/glossary#readability): How hard a text is to read, estimated from sentence and word length with formulas such as Flesch reading ease.
- [Thin content](/glossary/thin-content): A page with too little substantive content to be useful, judged here against word count and the site's own norm.
- [Title tag](/glossary/title-tag): The `<title>` element in the page head; browsers show it in the tab and search engines usually use it as the result headline.
- [X-Content-Type-Options](/glossary#x-content-type-options): The nosniff header that stops browsers guessing a response's type instead of trusting Content-Type.
