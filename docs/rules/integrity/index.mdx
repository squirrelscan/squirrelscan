Site Integrity rules answer a question audit tools usually skip: is this site hacked? A compromised page is an anomaly by construction, off-theme, hidden from your own navigation, impersonating a brand, or carrying an obfuscated payload. squirrelscan already has every page's DOM, scripts, links and sitemap from the crawl, so most of these rules look for those patterns without any extra request. Two read the results of an opt-in step that does send requests, and both are off by default: [Cloaking](/rules/integrity/cloaking) re-fetches a capped set of suspicious paths as Googlebot, and [Known malicious URL](/rules/integrity/known-malicious-url) checks your URLs and outbound links against threat feeds.

## Correlation gating (low false positives)

A single suspicious signal is rarely proof of compromise: a big inline script, one off-theme page, or a brand mention can all be innocent. So high-severity integrity findings require **at least two corroborating signals** on the same page (for example brand-impersonation **and** an obfuscated script). A lone signal is reported as **info** for review, not flagged as a failure. This is what keeps a legitimate "we integrate with Calendly" page from ever tripping the brand-impersonation rule.

These rules run **locally**, no login required.

## Run only these rules

```bash
squirrel audit https://example.com --rule-include integrity
```

## Where to start

These carry the highest severity and weight in the category.

- [Kit signature: matching a page against known phishing kits](/rules/integrity/kit-signature): A phishing kit reuses the same markup and strings on every site it lands on. squirrel matches each page against bundled kit signatures.
- [Known malicious URL: checking against threat feeds](/rules/integrity/known-malicious-url): A page can be listed by Safe Browsing before you notice anything wrong. squirrel checks your URLs and outbound links against reputation feeds.
- [Cloaking: showing Googlebot a different page](/rules/integrity/cloaking): An injected payload can hide from you by branching on user-agent or a query token. squirrel re-fetches suspicious paths and compares the responses.
- [Brand impersonation: a sign-in page that is not the brand's](/rules/integrity/brand-impersonation): A 'Sign in with Google' control pointing at a host that is not Google is a phishing pattern. squirrel checks where credential controls actually go.
- [Fake authentication overlay: full-screen login iframes](/rules/integrity/fake-auth-overlay): A fixed, full-viewport, high z-index iframe with an auth identifier is a credential-harvesting overlay. squirrel measures the geometry and the intent.

## Key terms

- [Cloaking](/glossary#cloaking): Serving search engines or particular user agents different content from what visitors see, a Google spam policy violation.
- [Doorway page](/glossary#doorway-page): A page made to rank for a query and funnel visitors elsewhere, often many near-identical pages per keyword or city.
- [Hacked site signals](/glossary#hacked-site): The traces a compromise leaves on a site: injected pages off the theme, phishing kits, obfuscated scripts and known malicious URLs.
- [Orphan page](/glossary/orphan-page): A page that no other crawled page links to, so crawlers and readers only reach it through a sitemap or a direct URL.
