## What X-Frame-Options is

`X-Frame-Options` is a response header that tells the browser whether the page may be loaded inside a `<frame>`, `<iframe>`, `<embed>` or `<object>`. `DENY` refuses all framing, `SAMEORIGIN` allows it only from the same origin. Without one, an attacker can load your page invisibly over their own and capture clicks meant for their interface, which is clickjacking.

The header is superseded by the CSP `frame-ancestors` directive, which supports a source list rather than a single keyword and is the one modern browsers consult first. The `ALLOW-FROM` value never worked in Chrome and was removed from the others. Sending both headers is still common for older clients.

## What squirrel checks

The rule reads the response headers of the first crawled page and emits a single check named `x-frame-options`:

- Skipped when the crawl produced no pages. Message: `No pages to check`.
- Pass when `X-Frame-Options` is `DENY` or `SAMEORIGIN`, compared case-insensitively after trimming. A header sent twice and joined by the server, such as `DENY, DENY`, counts as that single value. Message: `X-Frame-Options header present`, with the raw value.
- Warn when the value contains `ALLOW-FROM`. Message: `ALLOW-FROM is deprecated`, with `Use CSP frame-ancestors instead` as the value.
- Warn when the value is anything else, such as `ALLOWALL`, a typo like `DENNY`, or conflicting repeats like `DENY, SAMEORIGIN`, unless the CSP already has `frame-ancestors` (see the next item). Browsers ignore an invalid value, so the page can still be framed. Message: `Unrecognised X-Frame-Options value: <value>`, with `Browsers ignore it. Use DENY or SAMEORIGIN, or CSP frame-ancestors` as the value. Long values are cut at 80 characters.
- Pass when there is no valid `X-Frame-Options` header but the `Content-Security-Policy` header has a `frame-ancestors` directive. The directive is matched by name: each policy is split on `;`, and the first token of a directive must be `frame-ancestors`, case-insensitively. Text that merely contains it, such as a source URL, does not count. Message: `Clickjacking protection via CSP frame-ancestors`.
- Warn when neither is present. Message: `No clickjacking protection`, with `Add X-Frame-Options: DENY or CSP frame-ancestors` as the value.

## How to fix it

```
Content-Security-Policy: frame-ancestors 'self'
X-Frame-Options: SAMEORIGIN
```

Set both on every HTML response. Use `frame-ancestors 'none'` and `DENY` when nothing should ever frame the page. If a partner genuinely embeds you, list their origin in `frame-ancestors` rather than dropping the header, and keep `SAMEORIGIN` as the legacy fallback.

## Enable / disable

### Disable this rule

```toml squirrel.toml
[rules]
disable = ["security/x-frame-options"]
```

### Disable all Security rules

```toml squirrel.toml
[rules]
disable = ["security/*"]
```

### Enable only this rule

```toml squirrel.toml
[rules]
enable = ["security/x-frame-options"]
```

`enable` replaces the default `["*"]`, so this is the only rule selected. Leave `disable` out: a rule that matches any `disable` pattern is skipped even when `enable` names it. Only an `enabled` setting under a rule's own `[rule_options]` table overrides both lists.
