---

<Warning>**Retired rule** - this rule is disabled by default and its check is a no-op. It cannot invoke a model. See [Cloud rules](/cloud/rules) for the checks that do run.</Warning>

## What AI content detection is

AI content detection estimates whether a passage was written by a language model. Detectors work on statistical fingerprints of the text and they are not reliable at the level of a single page: human writing on technical subjects scores as machine-written often enough that acting on the result costs more than it saves.

Google's guidance on the subject is about the content, not its production method. Its documentation on AI-generated content says the reward goes to content that is helpful and original, however it was made, and that using automation to game rankings is what its spam policies address.

## What squirrel checks

Nothing. The rule is retired and hard-guarded so that it can never call a model. Its previous implementation made one model call per page with no credit charge wired to it, which was an uncatalogued cost, and it was replaced with a no-op rather than left running.

- `ai-content`, skipped with the message `AI content detection is retired` and the skip reason `Retired pending a metered opt-in endpoint`. This is the only result the rule can produce.

The rule is also marked disabled in its metadata, so it does not run unless it is explicitly enabled, and enabling it produces the same skip. Re-enabling detection for real requires a metered server endpoint and an opt-in before any model call.

## How to fix it

There is nothing to fix. The check is a no-op and the skip carries no weight in the score.

If you want the checks that do read the content with a model, [ai/llm-parsability](/rules/ai/llm-parsability) scores how well a model can extract a page's facts and [ai/page-type-match](/rules/ai/page-type-match) compares what a page reads as against what its markup declares. Both are included in the audit base charge on a logged-in run.

## Enable / disable

### Enable this rule

```toml squirrel.toml
[rules]
enable = ["ai/ai-content"]
```

### Disable this rule

```toml squirrel.toml
[rules]
disable = ["ai/ai-content"]
```

### Enable all AI rules

```toml squirrel.toml
[rules]
enable = ["ai/*"]
```
