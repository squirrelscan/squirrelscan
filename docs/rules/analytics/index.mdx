Analytics rules read what a page loads for measurement and whether it respects consent. One inventories the platforms present, from tag managers to privacy-focused alternatives. One flags a tag installed twice on a page. The last checks for Google Consent Mode v2, which Google requires for advertising traffic from the EEA. The platform inventory is informational: what you measure with is your decision, and this category reports it rather than judging it. A tag installed twice is a warning, because it makes every number wrong.

## Run only these rules

```bash
squirrel audit https://example.com --rule-include analytics
```

## Where to start

These carry the highest severity and weight in the category.

- [Duplicate analytics tags: the same tag installed twice](/rules/analytics/duplicate-tags): squirrel warns when one page loads the same Google Analytics 4 ID, Tag Manager container or analytics site ID more than once, which counts every visit twice.
- [Google Consent Mode v2: the four consent parameters](/rules/analytics/consent-mode): Google Ads in the EEA requires Consent Mode v2. squirrel checks for the consent call and for the two parameters v2 added.
- [Analytics tracking: which platforms a page loads](/rules/analytics/gtm-present): squirrel inventories the analytics on each page, from Google Tag Manager and GA4 to Plausible, Matomo, Segment and session-replay tools.
