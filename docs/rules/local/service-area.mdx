## What a service area page is

A service area page is a page about one place a business serves, usually one per city or neighbourhood. Sites that publish them normally put an index at a path such as `/locations` or `/service-areas` and hang the individual pages under it. That index is what this rule looks for.

They apply to a business that travels to customers, such as a plumber, a mover or a clinic with several branches. The same coverage is expressed in markup with `areaServed` on the business node, which squirrel's [schema/local-business](/rules/schema/local-business) rule accepts in place of a street address.

## What squirrel checks

The rule runs once per crawl and emits one check:

- `service-area`: tests the pathname of every crawled URL against five patterns, matched case-insensitively and anchored to the end of the path, with an optional trailing slash: `/location` or `/locations`, `/service-area` or `/service-areas`, `/area-served` or `/areas-served`, `/cities`, and `/neighborhood` or `/neighborhoods`. Any match passes with the message `N location/service area page(s) found` and lists the matching paths as items. No match reports at info status with the message `No dedicated location pages found` and the value `Consider adding for multi-location businesses`. Severity info.

A crawl with no pages emits the same check as skipped, with the message `No pages available for analysis`. The whole rule is skipped, with the reason shown in the report, when the site profile says the site is not a local business.

## How to fix it

```html
<a href="/locations">Locations</a>
```

Publish a hub at one of the paths above and link it from the main navigation so the crawl reaches it.

The patterns are anchored to the end of the pathname, so only the hub matches. A site with `/locations/san-francisco` and `/locations/oakland` but no `/locations` index reports `No dedicated location pages found`, because neither child path ends in `locations`. Adding the index page fixes the finding and is worth doing anyway. A hub under a different name, such as `/where-we-work`, is also not matched.

## Enable / disable

### Disable this rule

```toml squirrel.toml
[rules]
disable = ["local/service-area"]
```

### Disable all Local SEO rules

```toml squirrel.toml
[rules]
disable = ["local/*"]
```

### Enable only this rule

```toml squirrel.toml
[rules]
enable = ["local/service-area"]
disable = ["*"]
```
