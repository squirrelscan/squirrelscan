URL Structure rules read the address of each crawled page: its case, its word separators, its length and depth, its query parameters and its trailing slash. Most of them are conventions rather than defects, so their severities are low and their findings are worth applying to new URLs rather than retrofitting to old ones. The exception is `url/slug-convention`, which measures the site against its own dominant form and reports the minority, because mixed conventions are how duplicate-content and canonical bugs start.

## Run only these rules

```bash
squirrel audit https://example.com --rule-include url
```

## Where to start

These carry the highest severity and weight in the category.

- [Special characters in a URL path: what breaks and why](/rules/url/special-chars): Spaces, percent signs and non-ASCII characters in a path break when copied and pasted. squirrel decodes the path and reports what it finds.
- [Underscores in URLs: why hyphens separate words](/rules/url/hyphens): Google reads blue-shoes as two words and blue_shoes as one. squirrel flags every crawled path containing an underscore.
- [Uppercase in a URL: the duplicate content it creates](/rules/url/lowercase): Most servers treat /Page and /page as two URLs serving the same content. squirrel flags every crawled path containing a capital letter.
- [Mixed URL conventions: finding the minority form](/rules/url/slug-convention): Half your paths ending in a slash and half not is how canonical bugs start. squirrel computes your site's own norm and reports what deviates.
- [Non-descriptive URL slug: numeric IDs and generic patterns](/rules/url/slug-keywords): A slug like /p/48213 tells a reader and a crawler nothing. squirrel classifies the last path segment and flags the ID-shaped ones.

## Key terms

- [Crawl budget](/glossary#crawl-budget): The number of URLs a search engine is willing and able to crawl on a site in a given time, set by crawl capacity and crawl demand.
- [Duplicate content](/glossary/duplicate-content): The same or near-identical content reachable at more than one URL, or repeated titles and descriptions across pages.
- [Trailing slash](/glossary#trailing-slash): Whether URLs end in /; /page and /page/ are different URLs, so a site should pick one and redirect the other.
- [URL parameters](/glossary#url-parameters): Key-value pairs after ? in a URL; tracking and sort parameters can multiply URLs for the same content.
- [URL slug](/glossary/url-slug): The readable last part of a URL path; short, lowercase, hyphen-separated words work best.
