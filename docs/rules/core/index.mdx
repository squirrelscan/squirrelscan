Core SEO rules cover the declarations every page makes about itself: the title and description a search result is built from, the canonical URL that consolidates duplicates, the doctype and charset the browser needs before it parses anything, the H1, the favicon, and the robots directives that decide whether the page appears at all. Most run per page; two compare titles and canonical form across the whole crawl.

## Run only these rules

```bash
squirrel audit https://example.com --rule-include core
```

- [Meta description length: the 120 to 160 character range](/rules/core/meta-description): A page with no meta description, or one outside 120 to 160 characters. squirrel measures it on every crawled page.
- [Missing or multiple H1: what squirrel expects on a page](/rules/core/h1): A page with no H1, more than one, or an empty one. squirrel checks the heading on every crawled page.
- [Link rel=canonical header vs the HTML tag: the mismatch](/rules/core/canonical-header): A page declaring one canonical in an HTTP header and a different one in the markup. squirrel parses the header and compares.
- [nosnippet and max-snippet:0: pages with no search snippet](/rules/core/nosnippet): A robots directive that stops search engines showing any description under the result. squirrel reads the robots meta on every page.

## Key terms

- [Canonical URL](/glossary#canonical-url): The URL a page declares, with `<link rel="canonical">` or a Link header, as the preferred address for its content.
- [Character encoding](/glossary#character-encoding): The mapping from bytes to characters (normally UTF-8) declared in the Content-Type header or a meta charset tag; a mismatch produces mojibake.
- [Duplicate content](/glossary#duplicate-content): The same or near-identical content reachable at more than one URL, or repeated titles and descriptions across pages.
- [Heading hierarchy](/glossary#heading-hierarchy): The nesting of h1 to h6 headings that gives a page its outline for readers, screen readers and parsers.
- [HTML validity](/glossary#html-validation): Whether the markup parses as intended: closed elements, head-only tags in the head, and no raw markup printed as text.
- [Meta description](/glossary#meta-description): A `<meta name="description">` summary of the page that search engines may use as the result snippet.
- [noindex](/glossary#noindex): A robots directive, in a meta tag or the X-Robots-Tag header, that asks search engines to keep a page out of their index.
- [Open Graph](/glossary#open-graph): A set of og: meta properties (title, description, image, url) that controls how a link previews when it is shared.
- [Robots meta tag](/glossary#robots-meta-tag): A `<meta name="robots">` tag carrying page-level directives such as noindex, nofollow, nosnippet and max-snippet.
- [Title tag](/glossary#title-tag): The `<title>` element in the page head; browsers show it in the tab and search engines usually use it as the result headline.
- [Trailing slash](/glossary#trailing-slash): Whether URLs end in /; /page and /page/ are different URLs, so a site should pick one and redirect the other.
