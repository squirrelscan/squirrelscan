## What the meta description is

The meta description is a summary a page offers for use in a search result snippet. Google is explicit that it is not a ranking factor and that it uses the description only when it judges it a better summary than text drawn from the page, which happens for roughly half of results.

That still makes it worth writing. When the page has no description, the snippet is assembled from whatever text sits near the query terms, which on a page with a long navigation or a cookie banner can be nothing useful. Length matters for the same reason as the title: a snippet is truncated at display width, and text past that is written for nobody.

## What squirrel checks

The rule runs on every crawled page against the parsed description. It emits one check named `meta-description`:

- Failing with the message `Missing meta description` and a null value when there is none.
- Warning with the message `Description too short` under 120 characters, or `Description too long` over 160. Both carry the description as the value, `120-160 characters` as the expectation, and an item holding the page URL with the first 50 characters and the length.
- Passing with the message `Description length OK` and the description as the value.

Length is counted in characters of the parsed description. Severity is error and weight is 7.

## How to fix it

```html
<meta
  name="description"
  content="How the build cache stores compiled output between runs, when it invalidates, and the three settings that control it."
/>
```

Write one per page, summarising that page. A description repeated across a section is worse than none, because it tells a reader nothing that distinguishes the pages.

The common false positive is a page whose description is deliberately absent so that Google composes a snippet from the content, which is a defensible choice on a long reference page. The rule reports it as missing either way.

|---|---|
| **Rule ID** | `core/meta-description` |
| **Category** | [Core SEO](/rules/core) |
| **Scope** | Per-page |
| **Severity** | error |
| **Weight** | 7/10 |

## Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `min_length` | number | `120` | Minimum description length |
| `max_length` | number | `160` | Maximum description length |

### Configuration example

```toml squirrel.toml
[rules."core/meta-description"]
min_length = 120
max_length = 160
```

## Enable / disable

### Disable this rule

```toml squirrel.toml
[rules]
disable = ["core/meta-description"]
```

### Disable all Core SEO rules

```toml squirrel.toml
[rules]
disable = ["core/*"]
```

### Enable only this rule

```toml squirrel.toml
[rules]
enable = ["core/meta-description"]
disable = ["*"]
```
