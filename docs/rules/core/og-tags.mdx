## What Open Graph tags are

Open Graph is a set of `<meta property="og:...">` tags that tell a link preview what to show. Facebook defined it, and LinkedIn, Slack, Discord, WhatsApp and most other clients read the same tags. Without them a share falls back to whatever the client can scrape, which is usually the title element and the first image it finds.

Four tags carry the preview: `og:title`, `og:description`, `og:image` and `og:type`. `og:url` names the canonical address for the shared object. `og:image` is the one that changes how a link looks in a feed, and the recommended size is 1200 by 630 pixels.

## What squirrel checks

The rule runs on every crawled page against the parsed Open Graph values. It emits one to four checks, one per missing tag plus a summary:

- `og-title`: warns with the message `Missing og:title` and a null value.
- `og-description`: warns with the message `Missing og:description` and a null value.
- `og-image`: warns with the message `Missing og:image - social shares will lack imagery` and a null value.
- `og-type`: reports at info status with the message `Missing og:type (defaults to website)` and a null value.
- `og-tags`: passes with the message `Essential Open Graph tags present` and a value showing the first 30 characters of the title, emitted only when title, description and image are all present.

`og:type` is informational and does not stop the summary passing, because the protocol's default of `website` is right for most pages. Each missing tag is its own check, so a page missing all three essentials produces three warnings rather than one. The rule checks presence and never validates a value, so an `og:image` pointing at a URL that returns 404 passes.

## How to fix it

```html
<meta property="og:title" content="Configuring the build cache" />
<meta property="og:description" content="How the build cache stores compiled output between runs." />
<meta property="og:image" content="https://example.com/og/build-cache.png" />
<meta property="og:url" content="https://example.com/guides/build-cache" />
<meta property="og:type" content="article" />
```

Use an absolute URL for the image, since some clients do not resolve a relative one. 1200 by 630 pixels is the size that renders correctly in the widest set of clients.

The common false positive is a page whose tags are injected on the client. squirrel reads the HTML the server sent unless [browser rendering](/guides/browser-rendering) is on, and no share client runs JavaScript either, so a client-injected Open Graph tag is genuinely absent for the audience that matters.

## Enable / disable

### Disable this rule

```toml squirrel.toml
[rules]
disable = ["core/og-tags"]
```

### Disable all Core SEO rules

```toml squirrel.toml
[rules]
disable = ["core/*"]
```

### Enable only this rule

```toml squirrel.toml
[rules]
enable = ["core/og-tags"]
disable = ["*"]
```
