## What the title element is

The title element names the page. It is what a browser puts in the tab, what a bookmark saves, and one of the sources Google draws the link text of a result from. Google documents that it may use other text on the page instead when that describes the content better.

Length matters because of where it is displayed rather than because of any rule. A desktop search result truncates at roughly 600 pixels, which is around 60 characters of typical text, so anything past that is written for nobody. Too short usually means the title is a single word that could describe any page on the site.

## What squirrel checks

The rule runs on every crawled page against the parsed title. It emits one or two checks:

- `meta-title` and `document-title`, both failing with the messages `Missing page title` and `Missing document title` and a null value, when there is no title. These are the only two checks emitted in that case.
- `meta-title`, warning with the message `Title too short` when the title is under the minimum, or `Title too long` when it is over the maximum. Both carry the title as the value, `<min>-<max> characters` as the expectation, and an item holding the page URL with the first 50 characters of the title and its length. The defaults are 30 and 75 and both are configurable below.
- `meta-title`, passing with the message `Title length OK` and the title as the value.

Length is counted in characters of the parsed title, so an emoji counted by the browser as one glyph may count as two. Severity is error and weight is 8, the highest in this category.

## How to fix it

```html
<title>Configuring the build cache | Acme Docs</title>
```

Put the specific part first and the brand last, because that is the half that survives truncation. One title per page, describing that page rather than the site.

The common false positive is a title assembled on the client. squirrel reads the HTML the server sent unless [browser rendering](/guides/browser-rendering) is on, so a title set by JavaScript after load is reported as missing.

| | |
|---|---|
| **Rule ID** | `core/meta-title` |
| **Category** | [Core SEO](/rules/core) |
| **Scope** | Per-page |
| **Severity** | error |
| **Weight** | 8/10 |

## Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `min_length` | number | `30` | Minimum title length |
| `max_length` | number | `75` | Maximum title length |

### Configuration example

```toml squirrel.toml
[rules."core/meta-title"]
min_length = 30
max_length = 75
```

## Enable / disable

### Disable this rule

```toml squirrel.toml
[rules]
disable = ["core/meta-title"]
```

### Disable all Core SEO rules

```toml squirrel.toml
[rules]
disable = ["core/*"]
```

### Enable only this rule

```toml squirrel.toml
[rules]
enable = ["core/meta-title"]
disable = ["*"]
```
