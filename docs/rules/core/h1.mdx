## What the H1 is for

The H1 names what the page is about. A screen reader user jumping through headings lands on it first, and a search engine reads it alongside the title element as the page's own statement of its subject.

One per page is the working convention. HTML5's outline algorithm was meant to make multiple H1s meaningful inside sections, but no browser implemented it and assistive technology does not use it, so several H1s just means several competing claims about the page's subject. The H1 should say the same thing as the title element, usually with more room.

## What squirrel checks

The rule runs on every crawled page against the parsed heading data. It emits one check named `h1`:

- Failing with the message `No H1 tag found`, the value 0 and the expectation 1.
- Warning with the message `Multiple H1 tags found (N)`, the count as the value and the expectation 1.
- Warning with the message `H1 tag is empty` and an empty value when there is exactly one H1 with no text.
- Passing with the message `Single H1 tag present` and the heading text as the value.

The four outcomes are exclusive and the rule stops at the first that applies, so a page with two H1s is reported for the count and never checked for emptiness. Severity is error and weight is 7, the joint highest in this category, because a missing H1 is one of the few purely structural defects that is always worth fixing.

## How to fix it

```html
<main>
  <h1>Configuring the build cache</h1>
</main>
```

One per page, at the top of the main content, saying what the page is about. Where a design has a logo in an H1 in the header, that H1 belongs to the site rather than the page: make it a link with an image and give the page its own H1.

The common false positive is a heading rendered by JavaScript. squirrel reads the HTML the server sent unless [browser rendering](/guides/browser-rendering) is on, so a client-rendered H1 is not there to find.

## Enable / disable

### Disable this rule

```toml squirrel.toml
[rules]
disable = ["core/h1"]
```

### Disable all Core SEO rules

```toml squirrel.toml
[rules]
disable = ["core/*"]
```

### Enable only this rule

```toml squirrel.toml
[rules]
enable = ["core/h1"]
disable = ["*"]
```
