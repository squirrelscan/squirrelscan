Images rules cover the two things images most often break: page weight and layout. Weight is file size, format and whether the right size is served to the right screen; layout is the width and height attributes that reserve space before an image arrives. The category also carries the markup checks (alt attributes, picture fallbacks and figure captions) that decide whether an image means anything to a reader who cannot see it.

## Run only these rules

```bash
squirrel audit https://example.com --rule-include images
```

A few image checks live in [Performance](/rules/perf) instead: a lazy-loaded hero image, the hero's fetch priority and preload, and eager images in hidden carousel slides. Run both with `--rule-include images,perf`.

## Where to start

These carry the highest severity and weight in the category.

- [Oversized image files: the 200KB and 1MB thresholds](/rules/images/image-file-size): One unoptimised photo can outweigh every other asset on the page. squirrel measures the images the crawl fetched and reports the heavy ones.
- [\<picture\> without an \<img\>: the fallback that is required](/rules/images/picture-element): A picture element with no img child renders nothing at all. squirrel checks every picture on the page for its required fallback.
- [Broken images: empty and placeholder src attributes](/rules/images/broken-images): An img with an empty or placeholder src renders as a broken icon. squirrel collects image sources across the crawl and flags the malformed ones.
- [loading=lazy: which images need it and which must not](/rules/images/offscreen-lazy): Images below the fold that load eagerly compete with the ones the visitor can see. squirrel treats the first few images as above the fold.
- [Missing alt attribute: what an empty alt means](/rules/images/alt-text): An image with no alt attribute has no name for a screen reader. An empty alt is the correct way to say decorative, and squirrel accepts it.

## Key terms

- [Alt text](/glossary/alt-text): The alt attribute that gives an image a text alternative for screen readers, failed loads and search engines.
- [Broken link](/glossary/broken-link): A link whose target answers with an error, does not resolve, or is malformed.
- [Cumulative Layout Shift (CLS)](/glossary/cls): A score for how much visible content moves unexpectedly while the page is in use; good is 0.1 or less.
- [HTTP status code](/glossary/http-status-code): The three-digit code a server returns with every response; 2xx success, 3xx redirect, 4xx client error, 5xx server error.
- [Image width and height attributes](/glossary#image-dimensions): Declared width and height on `<img>` that let the browser reserve space before the file loads, preventing layout shift.
- [Lazy loading](/glossary/lazy-loading): Deferring off-screen images and iframes with loading="lazy" so they load as the visitor scrolls.
- [Modern image formats](/glossary#modern-image-formats): WebP and AVIF, which encode the same image in fewer bytes than JPEG or PNG.
- [Page weight](/glossary#page-weight): The total bytes a page downloads across HTML, CSS, JavaScript, images and fonts.
- [Responsive images](/glossary/responsive-images): Serving differently sized image files with srcset, sizes and `<picture>` so each device downloads one that fits.
- [WCAG](/glossary/wcag): The W3C's Web Content Accessibility Guidelines, organised as testable success criteria at levels A, AA and AAA; 2.2 is current.
