## What AGENTS.md is

`AGENTS.md` is a plain Markdown file that tells a coding agent how to work in a codebase: how to install dependencies, how to run the tests, which commands to use, and the conventions the project expects. It lives at the repository root and is read by the agent before it starts changing files.

It is aimed at a repository rather than at a website, so it matters for a site that has a public codebase behind it and not for a site that does not. Absence is never a defect here.

## What squirrel checks

The rule runs once per crawl against four probed paths, in this order: `/AGENTS.md`, `/agents.md`, `/.well-known/agents.md` and `/docs/AGENTS.md`. It emits one check:

- `agents-md`: reports at info status with the message `well-known probe data not available` when the probes did not run.
- `agents-md-present`: reports at info status with `AGENTS.md found at <path> (N bytes)` when a probe returned 200 with a body that did not sniff as HTML and read as Markdown. With no such hit anywhere, but a probe that returned 200 with an HTML body, it reports at info status with `<path> responded 200 but returned an HTML page (SPA fallback) — not a real AGENTS.md`. With no hit at all, the result depends on the rest of the site: a site that publishes `/llms.txt` gets a warning with `No AGENTS.md found — this site publishes llms.txt, so consider an AGENTS.md for coding agents too`, and every other site gets an info result with `No AGENTS.md found — consider adding one if this site has an associated codebase`.

That last condition is the whole design. Recommending `AGENTS.md` to every site would be noise on a restaurant's website, so the recommendation only fires where the site has already shown it is developer-facing by publishing `llms.txt`. The rule's severity is info, so even the warning is a recommendation and does not move the score.

## How to fix it

```markdown
# AGENTS.md

## Setup
`bun install`

## Tests
`bun test <file>` runs one file. Never run the suite bare.

## Conventions
TypeScript only. Format with oxfmt before committing.
```

Commit it at the repository root. Publishing it on the website is optional; this rule probes the site because that is what an audit can see.

The common false positive is a single-page application whose server returns `index.html` for every unmatched path, which is why the rule sniffs the body rather than trusting the status code.

## Enable / disable

### Disable this rule

```toml squirrel.toml
[rules]
disable = ["ax/agents-md"]
```

### Disable all Agent Experience rules

```toml squirrel.toml
[rules]
disable = ["ax/*"]
```

### Enable only this rule

```toml squirrel.toml
[rules]
enable = ["ax/agents-md"]
disable = ["*"]
```
