## What a well-known agent manifest is

A manifest at a fixed path lets an agent discover a service without a person reading documentation first. Three are in use.

- An MCP server card describes a Model Context Protocol endpoint: where it is and what transport it speaks.
- An A2A agent card, at `/.well-known/agent-card.json`, describes an agent another agent can talk to.
- An agent-skills manifest, at `/.well-known/agent-skills/index.json`, lists a packaged set of skills.

One older path is worth removing rather than adding. `/.well-known/ai-plugin.json` described a ChatGPT plugin, a format that has been retired. A stale one still sitting on a server describes a service that no longer works.

## What squirrel checks

The rule runs once per crawl against probed well-known paths. A probe counts as a hit when it returned 200, the body parsed as JSON, and it did not sniff as HTML. It emits one or more checks:

- `well-known-agent`: reports at info status with the message `well-known probe data not available` when the probes did not run. With probes but no hits it reports at info status with `No MCP server card, A2A agent card, or agent-skills manifest found` and the value `absent`.
- `well-known-agent-present`: one check per manifest found, at info status, with the message `MCP server card found at /.well-known/mcp.json`. When the JSON carries none of the keys `url`, `name`, `transport`, `endpoint` or `version`, the message gains the suffix ` (JSON present, but no plausible manifest fields recognized)`.
- `well-known-agent-deprecated`: emitted only when `/ai-plugin.json` or `/.well-known/ai-plugin.json` is a hit. It warns with the message `Found deprecated OpenAI plugin manifest at /.well-known/ai-plugin.json — this format was retired; remove it to avoid confusing modern agents`.

The MCP card is probed at four paths: `/.well-known/mcp/server-card.json`, `/.well-known/mcp.json`, `/.well-known/mcp` and `/.well-known/mcp-server`. Absence of every manifest is a single quiet info result and never a warning, because adoption is still rare. The one thing this rule warns about is the stale file.

## How to fix it

There is nothing to add unless the site backs an MCP server, an A2A agent or a skill set. If it does, publish the manifest at its conventional path:

```json
{
  "name": "Acme MCP",
  "version": "1.0.0",
  "url": "https://mcp.example.com",
  "transport": "streamable-http"
}
```

If the report names a deprecated plugin manifest, delete the file. It describes a format that no client uses.

There is no common false positive. A JSON document that happens to 200 at one of these paths is reported with the note about unrecognised fields rather than being counted as a working manifest.

## Enable / disable

### Disable this rule

```toml squirrel.toml
[rules]
disable = ["ax/well-known-agent"]
```

### Disable all Agent Experience rules

```toml squirrel.toml
[rules]
disable = ["ax/*"]
```

### Enable only this rule

```toml squirrel.toml
[rules]
enable = ["ax/well-known-agent"]
disable = ["*"]
```
