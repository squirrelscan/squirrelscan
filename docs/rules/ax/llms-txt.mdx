## What llms.txt is

`llms.txt` is a Markdown file at a site's root that points AI agents and answer engines at the content worth reading. The convention from llmstxt.org is an H1 with the site or project name, a short summary, then sections of Markdown links to key pages. A companion `llms-full.txt` inlines that content rather than linking to it.

It is a proposal, not a standard, and no crawler is obliged to fetch it. It costs one static file and it gives an agent a curated entry point instead of a sitemap of every URL you have. Absence is never a defect here.

## What squirrel checks

The rule runs once per crawl against the root `/llms.txt`, with `/.well-known/llms.txt` and `/docs/llms.txt` as fallbacks probed by the crawler. It emits one or two checks:

- `llms-txt`: reports at info status with the message `llms.txt data not available` when the probe did not run.
- `llms-txt-present`: fails with the message `/llms.txt returned 200 but the body is an HTML page (SPA fallback) — not a real llms.txt` when the file exists but its first 512 bytes start with `<!doctype html` or `<html`. With no root file but a real hit at one of the two alternate paths, it reports at info status with `No /llms.txt at the root, but found one at /docs/llms.txt`. With nothing anywhere it warns with `No /llms.txt found — consider adding one so AI agents can discover your key content`. With a real root file it reports at info status with `/llms.txt found (2048 bytes)`, adding `; /llms-full.txt also present` when that exists too.
- `llms-txt-format`: emitted only when a root file was found. It passes at info status with `Valid llms.txt format (14 links)`, or warns with `llms.txt format notes:` followed by the problems joined with `; `. The three possible notes are ``missing H1 title (should start with `# Name`)``, `no Markdown links found` and `3 malformed link URL(s)`.

An alternate-path hit counts only when the probe returned 200, the body did not sniff as HTML, and the content read as Markdown. The format check tests that the first non-empty line matches an H1 with text after the hash, counts every `[text](url)` link, and tries to parse each link URL against the site's base URL. The rule's severity is info, so a `warn` check surfaces as a recommendation and does not move the score. The SPA-fallback result is the exception: a file that claims to be curated content and is not is a `fail`.

## How to fix it

```markdown
# Acme Docs

> Deployment and configuration guides for Acme.

## Guides
- [Quickstart](https://example.com/docs/quickstart): install and first deploy.
- [Configuration](https://example.com/docs/config): every option, with defaults.
```

Serve it at `https://example.com/llms.txt` with a `text/plain` or `text/markdown` content type.

The common false positive is a single-page application whose server returns `index.html` for every unmatched path. The file appears to exist with a 200 status, which is why the rule sniffs the body and reports the fallback rather than reporting a valid file.

## Enable / disable

### Disable this rule

```toml squirrel.toml
[rules]
disable = ["ax/llms-txt"]
```

### Disable all Agent Experience rules

```toml squirrel.toml
[rules]
disable = ["ax/*"]
```

### Enable only this rule

```toml squirrel.toml
[rules]
enable = ["ax/llms-txt"]
disable = ["*"]
```
