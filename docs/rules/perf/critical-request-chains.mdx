## What a critical request chain is

A critical request chain is a sequence of requests that must complete in order before the page can render. The HTML arrives, the parser finds a stylesheet, the stylesheet arrives, and inside it an `@import` names another file that has to be fetched before anything can paint. Each link costs a full round trip, and round trips are the part of the load that a faster connection does not fix.

Depth matters more than count. Four independent blocking resources fetch in parallel; four chained ones fetch one after another. `@import` is the worst offender because the browser cannot even discover the second URL until the first file is parsed.

## What squirrel checks

The rule runs on every crawled page and emits one check:

- `critical-request-chains`, at info status with the message `No <head> element found` when the page has no head.
- `critical-request-chains`, warning with the message `N critical request chain(s) found` and listing up to ten members as items, each written `CSS: <href>` or `JS: <src>`. The details record the blocking CSS count, the blocking JS count, the import count, the number of preloads and any overflow.
- `critical-request-chains`, passing with the message `No critical request chains detected`, with the preload count in the details.

Three things are counted, all from `<head>` except the imports. A blocking stylesheet is a `link[rel="stylesheet"]` that is neither `media="print"` nor `disabled`. A blocking script is a `script[src]` with none of `async`, `defer` or `type="module"`. Every `@import` in every `<style>` element on the page adds one entry, reported as a single item naming the count.

The count is a count of blocking resources rather than a measured chain depth, since a static read of the HTML cannot see what a stylesheet fetches once parsed.

## How to fix it

```html
<style>/* styles the first screen needs */</style>
<link rel="stylesheet" href="/rest.css" media="print" onload="this.media='all'" />
<script src="/app.js" defer></script>
```

Replace every `@import` with a `<link>`, which lets the browser fetch in parallel instead of serially. Add `defer` to scripts and inline the styles the first screen needs.

The common false positive is `type="module"`, which this rule treats as non-blocking. A module script is deferred by default, so that is correct for parsing, but its dependency graph is itself a chain the rule cannot see.

## Enable / disable

### Disable this rule

```toml squirrel.toml
[rules]
disable = ["perf/critical-request-chains"]
```

### Disable all Performance rules

```toml squirrel.toml
[rules]
disable = ["perf/*"]
```

### Enable only this rule

```toml squirrel.toml
[rules]
enable = ["perf/critical-request-chains"]
disable = ["*"]
```
