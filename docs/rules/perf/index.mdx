---
title: "Performance"
description: "Page speed and loading performance"
---

Performance rules read the HTML and the response headers to find what makes a page slow: render-blocking resources, oversized CSS and JavaScript, missing caching and compression, and the markup patterns behind each Core Web Vital. They report the causes a static read can see, not the metrics themselves, which need a real browser to measure.

See [Core Web Vitals](https://squirrelscan.com/learn/core-web-vitals) for how an agent works through a report.
