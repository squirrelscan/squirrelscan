## What a duplicate library is

Two script tags loading the same library cost the bytes twice and, worse, can leave two copies in memory that do not share state. With React that means hooks failing at runtime. With jQuery it means whichever loaded last winning and any plugin registered against the first one disappearing.

Two different versions is the sharper version of the problem. It usually happens when a third-party embed brings its own copy of a library the page already loads, or when a tag manager injects one.

## What squirrel checks

The rule runs on every crawled page over its `<script src>` elements. It extracts a library name and, where the URL carries one, a version, then groups by name. It emits one or two checks:

- `duplicate-js-version-mismatch`: fails with the message `N library(s) loaded with different versions`, listing each as `<name> (versions: 3.6.0, 3.7.1)`.
- `duplicate-js-same-version`: warns with the message `N library(s) loaded multiple times`, listing each as `<name> (2x)`.
- `duplicate-js`: passes with the message `No duplicate JavaScript libraries detected`, recording how many scripts it analysed.

Names are matched from four URL shapes, in order: an unpkg path, a jsDelivr npm path, a cdnjs path, and a generic `/<name>[.-]<version>.js` path. When none matches, the leading run of letters, digits and hyphens in the filename becomes the name. Everything is lowercased.

A page with no parsed document emits nothing at all.

## How to fix it

Load each library once, from one place. Where a bundler is in use, that usually means marking the library external and providing it yourself rather than letting two chunks each include it:

```html
<script src="https://unpkg.com/react@18.3.1/umd/react.production.min.js"></script>
```

Where a third-party embed brings its own copy, the vendor usually has a build that uses the page's copy instead.

The common false positive comes from the last name-matching pattern. Two unrelated files whose names begin with the same word, such as `app-header.js` and `app-footer.js`, both reduce to `app` and are reported as one library loaded twice. Check the listed names before changing anything.

## Enable / disable

### Disable this rule

```toml squirrel.toml
[rules]
disable = ["perf/duplicate-js"]
```

### Disable all Performance rules

```toml squirrel.toml
[rules]
disable = ["perf/*"]
```

### Enable only this rule

```toml squirrel.toml
[rules]
enable = ["perf/duplicate-js"]
disable = ["*"]
```
