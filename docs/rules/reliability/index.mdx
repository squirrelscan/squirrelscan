Reliability rules check that what a page asks the browser to load actually loads. They read the scripts, stylesheets and fonts the crawl already fetched, so a bundle that returns 404 after a deploy shows up even when the HTML that references it is a 200. The category sits in the Performance score group, since a page whose main script never loads is slow to become usable, and the rules need no browser render.

## Disable all Reliability rules

```toml squirrel.toml
[rules]
disable = ["reliability/*"]
```

Every audit reports Reliability findings next to the performance, security and agent experience rules. See [Core Web Vitals](https://squirrelscan.com/learn/core-web-vitals) for how an agent works through a report.
