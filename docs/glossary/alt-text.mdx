**Alt text** is the text in an image's `alt` attribute: what a screen reader announces in place of the image, and what the browser shows when the image does not load.

WCAG 2.2 success criterion 1.1.1, Non-text Content, asks for a text alternative that serves the same purpose as the image. The W3C's image tutorials split images into two kinds. An informative image gets a short description of what it conveys. A decorative one gets an empty `alt=""`, so assistive technology skips it. Leaving the attribute out is the failure, because some screen readers then read out the file name.

## Why it matters

For a person using a screen reader, an image with no alt is often just its file name read aloud, something like `IMG_4031.jpg`. Redundant alt text wastes their time in a different way. Screen readers already announce "image", so "image of a chart" says it twice, and alt text that repeats the caption below it is read twice too. Google also reads alt text: its image guidelines say it uses alt text, along with computer vision and the page content, to work out what an image shows.

## How squirrelscan checks it

[images/alt-text](/rules/images/alt-text) reports a page where any `<img>` has no `alt` attribute at all. An empty or whitespace-only alt counts as decorative and passes, and the rule does not judge the quality of the text. [a11y/image-redundant-alt](/rules/a11y/image-redundant-alt) does look at the text: it flags alt that matches patterns such as "photo of" or a bare "logo", alt that matches the file name, and alt that repeats a `<figcaption>` or the text around the image. Two rules cover elements that are easy to forget. [a11y/input-image-alt](/rules/a11y/input-image-alt) reports a visible `<input type="image">` with no name, which is a submit button with nothing to announce. [a11y/object-alt](/rules/a11y/object-alt) reports a visible `<object>` with no label and no fallback text between its tags.

## How to fix it

Describe what the image conveys in its context, and mark decoration as decoration:

```html
<img src="/revenue.png" alt="Revenue by quarter, rising from Q1 to Q4" />
<img src="/divider.svg" alt="" />
<input type="image" src="/icons/search.svg" alt="Search" />
```

Skip "image of" and do not paste the caption into the alt ([the redundant alt fix](/rules/a11y/image-redundant-alt#how-to-fix-it)). An icon inside a button that already has a label takes `alt=""` ([the alt attribute fix](/rules/images/alt-text#how-to-fix-it)). An image input is a button, so its alt names the action, never `alt=""` ([the image input fix](/rules/a11y/input-image-alt#how-to-fix-it)). Put a link to the resource between an `<object>`'s tags ([the object fix](/rules/a11y/object-alt#how-to-fix-it)).
