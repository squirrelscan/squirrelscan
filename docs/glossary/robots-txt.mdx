**robots.txt** is a plain-text file at the root of a host that tells crawlers which paths they may request, with rules grouped by user-agent token.

The format is the Robots Exclusion Protocol, first defined by Martijn Koster in 1994 and published as RFC 9309 in 2022. A file holds `User-agent` groups, each with `Allow` and `Disallow` rules, plus optional `Sitemap` lines that can appear anywhere.

## Why it matters

robots.txt controls crawling, not indexing. Google says a disallowed page can still be indexed if other sites link to it, and the URL can show in results without a description. A `noindex` on a disallowed page is never read, because the crawler never fetches the page. The file is also a request: cooperative crawlers honour it, and nothing enforces it. Each AI crawler has its own token, so one file now carries separate decisions about search, AI search and training.

## How squirrelscan checks it

[crawl/robots-txt](/rules/crawl/robots-txt) checks that the file exists, parses without syntax errors, does not block all crawling for `User-agent: *`, references a sitemap and stays under Google's 500 KB limit. A request the site refused is reported as unknown, not missing. Two rules check robots.txt against the pages: [crawl/robots-meta-conflict](/rules/crawl/robots-meta-conflict) lists pages that are blocked and also carry `noindex`, and [crawl/indexability-conflicts](/rules/crawl/indexability-conflicts) lists pages blocked without one. Both decide blocking the way Google does, with the longest matching rule winning. [ax/ai-crawlers](/rules/ax/ai-crawlers) and [ax/content-signals](/rules/ax/content-signals) read the AI crawler groups and any `Content-Signal` lines.

## How to fix it

Serve the file from the host root as `text/plain` (see [the robots.txt fix](/rules/crawl/robots-txt#how-to-fix-it)):

```
User-agent: *
Allow: /

Sitemap: https://example.com/sitemap.xml
```

Keep `Disallow` for paths that waste crawl budget, such as faceted search and session URLs. To keep a page out of search results, allow the crawl and use `noindex` instead. Do not block the CSS, JavaScript or image paths a renderer needs.

## Run the check

```bash

```

## Related terms

- [noindex](/glossary/noindex): A robots directive, in a meta tag or the X-Robots-Tag header, that asks search engines to keep a page out of their index.
- [XML sitemap](/glossary/xml-sitemap): An XML file listing the URLs a site wants crawled, with optional lastmod dates, referenced from robots.txt or submitted to search engines.
- [AI crawler](/glossary/ai-crawler): A bot that fetches pages for AI companies, in three classes: training crawlers, AI search indexers and user-triggered fetchers, each with its own user-agent token.
- [Content Signals](/glossary#content-signals): Content-Signal lines in robots.txt that state whether content may be used for search, AI input or AI training.
- [Crawl budget](/glossary/crawl-budget): The number of URLs a search engine is willing and able to crawl on a site in a given time, set by crawl capacity and crawl demand.
