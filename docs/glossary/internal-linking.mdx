**Internal linking** is the set of links between pages of the same site, which carry crawlers and readers from page to page and show which pages the site treats as important.

Google's link guidance says it can generally only crawl a link that is an `<a>` element with an `href`. A click handler on a `<span>` is not a link to a crawler. Google says it uses links to find new pages to crawl and as a signal of relevance, and a sitemap supplements that discovery rather than replacing it. The text of each link also tells readers and search engines what the target is about.

## Why it matters

A page that nothing links to is hard to find, and a page linked only from the footer gets none of the context that a link from a related article gives. Navigation, headers and footers repeat on every page, so they say little about any one target. The links in body copy carry the context. Pages with no outgoing links leave readers and crawlers stuck. `rel="nofollow"` on an internal link asks search engines not to follow it, which works against the site's own pages.

## How squirrelscan checks it

The rules count crawlable, resolvable internal links, and leave `nofollow` links out of inbound totals. [links/internal-links](/rules/links/internal-links) warns on a page with fewer than 1 or more than 100 internal links, both configurable. A large sitewide menu pushes every page toward the ceiling. [links/orphan-pages](/rules/links/orphan-pages) reports pages with fewer than 2 inbound links, and [links/weak-internal-links](/rules/links/weak-internal-links) reports pages with exactly one. [links/no-contextual-inbound](/rules/links/no-contextual-inbound) finds pages linked only from `nav`, `header`, `footer` or `aside`, and skips legal pages because footer-only links are expected there. All three inbound-link rules skip when the crawl stops at its page cap because an uncrawled page may supply another link. [links/dead-end-pages](/rules/links/dead-end-pages) flags pages with no outgoing internal link. [links/nofollow-internal](/rules/links/nofollow-internal) lists internal links marked `nofollow`. The homepage and the page the audit started from are never reported as orphans.

## How to fix it

Link related pages from the body, with text that names the target:

```html
<p>
  The cache is keyed on the lockfile, so see
  <a href="/guides/lockfiles">how lockfiles change between installs</a>.
</p>
```

Add links from the hub or category page and from articles on the same topic ([the orphan fix](/rules/links/orphan-pages#how-to-fix-it), [the contextual link fix](/rules/links/no-contextual-inbound#how-to-fix-it)). Give dead-end pages a related-content block or a breadcrumb ([the dead-end fix](/rules/links/dead-end-pages#how-to-fix-it)). Remove `nofollow` from internal links, and use robots.txt or `noindex` for pages that should not be crawled or indexed ([the nofollow fix](/rules/links/nofollow-internal#how-to-fix-it)). On a site with a full sidebar, raise `max_internal_links` rather than cutting navigation ([the link count fix](/rules/links/internal-links#how-to-fix-it)).

## Run the check

{/* glossary:run:start */}

```bash
squirrel audit https://example.com --rule-include links/internal-links,links/weak-internal-links,links/no-contextual-inbound,links/dead-end-pages,links/orphan-pages,links/nofollow-internal
```

## Related terms

- [Orphan page](/glossary/orphan-page): A page that no other crawled page links to, so crawlers and readers only reach it through a sitemap or a direct URL.
- [Anchor text](/glossary/anchor-text): The visible, clickable text of a link, which tells readers and search engines what the target is about.
- [rel=nofollow](/glossary#nofollow): A link attribute value asking search engines not to associate the linking page with the target; a hint, not a block.
- [Broken link](/glossary/broken-link): A link whose target answers with an error, does not resolve, or is malformed.
