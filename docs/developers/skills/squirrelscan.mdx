`squirrelscan` is the core Agent Skills `SKILL.md` for the squirrelscan website audit tool: the skill that teaches Claude Code, Codex, Cursor and other coding agents to operate the `squirrel` CLI. squirrelscan crawls a website like a search engine and checks every page against 360+ audit rules in 22 categories. The categories include SEO, performance, security, accessibility, content, structured data and agent experience. It returns a health score and concrete, fixable issues. Use it for installing and updating the CLI, login, running audits and reading reports.

New to skills? Start with the [skills overview](/developers/skills/overview).

## What it does

- Runs `squirrel audit <url>` and reads the report.
- Uses `--format llm` when an agent reads the output, and JSON when it needs every affected page.
- Explains the three audit levels: `quick` (25 pages), `surface` (100 pages, one page per URL pattern) and `full` (500 pages).
- Tells you before a logged-in audit what it costs and what it leaves behind, and offers `--no-publish`, `--ephemeral` and `--offline`.
- Sets the probing level by who owns the website: `--passive` for websites you do not own, and `--aggressive` or `--pentest` only when you own or may test the website.
- Handles exit codes and audits that did not run: `3` blocked, `4` redirected to another website, `5` unreachable. None of these is a score.
- Reads skipped and not-checked rules as unchecked, never as clean.
- Covers publishing and sharing reports, diffs, cloud credits, API keys and MCP server setup.
- Covers the entity map: the site-wide graph of entities a website declares in JSON-LD, and fixing identity problems such as an organization declared separately on every page.
- Offers the companion skills when a request matches, and loads a reference file only when the task needs it.

## Commands it covers

`squirrel audit`, `crawl`, `analyze`, `report`, `entities`, `init`, `config`, `auth`, `keys`, `credits`, `mcp`, `skills`, `self` and `feedback`. Every command supports `--help`.

```bash
squirrel skills install
```

```bash
squirrel skills install squirrelscan
```

## Requirements

The squirrel CLI installed and in your `PATH`, or the hosted squirrelscan MCP server connected (`https://mcp.squirrelscan.com/mcp`). Check the CLI with `squirrel --version`. Setup steps are in [install](/install) and [MCP clients](/developers/mcp-clients).

Install the CLI on macOS or Linux:

```bash
curl -fsSL https://install.squirrelscan.com | bash
```

## How it works

1. Run `squirrel auth status` before the first audit and tell you the cost, the dashboard and schedule side effects and what gets published.
2. Run `squirrel audit` at the level you need, with probing set by who owns the website.
3. Read the report: `--format llm` is a sample, JSON is the full list, and a `Not checked:` line names rules that did not run.
4. Treat a issue as a issue, not always a bug: ask before changing a deliberate `noindex` or `robots.txt` block.
5. Load a reference for installation, accounts and credits, reports, MCP, entity maps, configuration or maintenance when the task needs one.
