`seo-audit` is an Agent Skills `SKILL.md` from squirrelscan: a technical SEO audit skill and website SEO checker for coding agents. It runs squirrelscan's audit rules through the squirrel CLI or the hosted squirrelscan MCP server. It works in Claude Code, Codex, Cursor and other agents, and fixes template-level issues first. It finds technical and on-page problems; it does not know what your searchers want or how pages rank.

Version 0.1.1. New to skills? Start with the [skills overview](/developers/skills/overview).

## What it does

- Checks crawlability and indexability: `robots.txt`, sitemaps, canonicals, noindex and server errors.
- Checks titles, descriptions, headings, duplicate content, URLs, social tags, languages and image alt text.
- Groups issues by rule, then by template: a title over 60 characters on 41 pages is one change to a title template.
- Fixes in indexability-first order: crawl and index, discovery, what each page says, duplicate or thin content, then URLs, social, language and images.
- Checks intent before calling anything broken, since a `noindex`, a `robots.txt` block or a canonical to another page can be deliberate.
- Leaves staging and preview `noindex` in place.
- Points to where the fix lives in Next.js metadata, WordPress with Yoast SEO, Shopify, Webflow and static websites.
- Does not promise rankings: it says what was fixed and what the tool cannot judge.

## Questions it answers

- Run an SEO audit on my website
- Why aren't my pages indexed?
- Check my meta tags and sitemap
- Which pages have missing or duplicate titles and meta descriptions?
- Are my canonicals pointing at the right URLs?
- Is my robots.txt blocking pages I want indexed?
- Is my sitemap valid, and does it list live URLs only?
- How do I fix SEO titles in Next.js metadata or Yoast?

## Requirements

The squirrel CLI installed and in your `PATH`, or the hosted squirrelscan MCP server connected (`https://mcp.squirrelscan.com/mcp`). Check the CLI with `squirrel --version`. Setup steps are in [install](/install) and [MCP clients](/developers/mcp-clients).

Install the CLI on macOS or Linux:

```bash
curl -fsSL https://install.squirrelscan.com | bash
```

## Example prompts

Paste one of these into your coding agent:

```text
Run an SEO audit on https://example.com
Why aren't my pages indexed? Check robots, canonicals and the sitemap
Check my meta tags and sitemap and fix the title template
```

The agent runs the crawl, core, content, URL, social, language and image rules at surface level. It fixes the templates behind the issues and re-audits with `--refresh`.

## How it works

1. Check the CLI and login status and tell you the cost.
2. Run `squirrel audit` at `--level surface` with the SEO-related rule categories.
3. Read errors in `crawl` and `core` first, grouped by template, and check intent before changing anything.
4. Fix in order and re-audit with `--refresh` after the deploy.
5. Stop when a `--level full` re-audit has no error-severity issues in `crawl` and `core`, and what is left is judgment listed for you.
