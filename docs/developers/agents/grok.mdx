The `grok` CLI adds remote MCP servers with `grok mcp add`, so squirrelscan's tools are available in a session.

## 1. Install the CLI

The skills and local audits run through the `squirrel` binary.

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL https://install.squirrelscan.com | bash
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    iwr -useb https://install.squirrelscan.com/install.ps1 | iex
    ```
  </Tab>
</Tabs>

Local audits run entirely on your machine. Signed out, they need no account and cost nothing; signed-in audits spend credits. Verify with `squirrel --version`.

## 2. Add the MCP server

```bash
grok mcp add --transport http squirrelscan https://mcp.squirrelscan.com/mcp
```

## 3. Sign in with OAuth

Servers that require OAuth start a browser sign-in the first time you use them, so there is nothing to paste into the config. Use a machine with a browser.

<Note>The sign-in step has not been verified by a human yet.</Note>

## 4. Install the skills

```bash
squirrel skills install
```

That installs `audit-website` (the fix loop) and `squirrelscan` (operating the CLI). See [`squirrel skills`](/cli/skills).

## 5. Run an audit

Ask for the audit, then hand it the fixes:

```text
Audit https://nutshop.squirrelscan.com with squirrelscan and list the top issues by severity.
```

```text
Fix every core/title-missing and images/alt-missing issue, then re-audit to confirm the score went up.
```

<Note>The hosted MCP server crawls from squirrelscan's cloud, so it needs a publicly reachable URL. Use the CLI or [`squirrel mcp`](/cli/mcp) for `localhost` and private staging websites.</Note>
