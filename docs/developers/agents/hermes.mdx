To run a website audit in Hermes Agent, add squirrelscan under `mcp_servers` in `config.yaml` and ask it to audit your site.

Hermes Agent is Nous Research's open source agent. It speaks MCP over HTTP with OAuth, so squirrelscan's tools appear as `mcp_*` tools in a session.

## 1. Install the CLI

The skills and local audits run through the `squirrel` binary.

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL https://install.squirrelscan.com | bash
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    iwr -useb https://install.squirrelscan.com/install.ps1 | iex
    ```
  </Tab>
</Tabs>

Local audits run entirely on your machine. Logged out, they need no account and cost nothing; logged-in audits spend credits. Verify with `squirrel --version`.

## 2. Add the MCP server

Add this block to `~/.hermes/config.yaml`:

```yaml
mcp_servers:
  squirrelscan:
    url: "https://mcp.squirrelscan.com/mcp"
    auth: oauth
```

## 3. Log in with OAuth

Run the login on a machine with a browser:

```bash
hermes mcp login squirrelscan
```

Hermes registers a client, opens the browser, and stores the token itself. Check the connection:

```bash
hermes mcp test squirrelscan
```

<Warning>Do not use `--flow device` with squirrelscan. The server does not offer the device code flow, and Hermes stops with "Server does not advertise device authorization".</Warning>

**Headless machines.** Run `hermes mcp login squirrelscan` over SSH with the loopback callback forwarded to your laptop, as the [Hermes guide to OAuth over SSH](https://hermes-agent.nousresearch.com/docs/guides/oauth-over-ssh) describes. For unattended hosts, use an API key header instead of OAuth.

<Note>The final login step has not been verified by a human yet.</Note>

## 4. Install the skills

```bash
squirrel skills install
```

That installs `audit-website` (the fix loop) and `squirrelscan` (operating the CLI). Hermes also reads skills from `~/.hermes/skills`. See [`squirrel skills`](/cli/skills).

## 5. Run an audit

Ask for the audit, then hand it the fixes:

```text
Audit https://nutshop.squirrelscan.com with squirrelscan and list the top issues by severity.
```

```text
Fix every core/title-missing and images/alt-missing issue, then re-audit to confirm the score went up.
```

<Note>The hosted MCP server crawls from squirrelscan's cloud, so it needs a publicly reachable URL. Use the CLI or [`squirrel mcp`](/cli/mcp) for `localhost` and private staging websites.</Note>
