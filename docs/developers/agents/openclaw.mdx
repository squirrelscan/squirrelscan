To run a website audit in OpenClaw, register the squirrelscan MCP server with `openclaw mcp set` and ask it to audit your site. For a step-by-step walkthrough, see the [OpenClaw guide](https://squirrelscan.com/for/openclaw).

OpenClaw is an open source assistant that runs on your own hardware. It manages MCP servers under `mcp.servers` in its config, so squirrelscan's tools are available in every chat.

## 1. Install the CLI

The skills and local audits run through the `squirrel` binary.

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL https://install.squirrelscan.com | bash
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    iwr -useb https://install.squirrelscan.com/install.ps1 | iex
    ```
  </Tab>
</Tabs>

Local audits run entirely on your machine. Logged out, they need no account and cost nothing; logged-in audits spend credits. Verify with `squirrel --version`.

## 2. Add the MCP server

Always set `transport`. OpenClaw defaults to SSE, and squirrelscan serves streamable HTTP only.

```bash
openclaw mcp set squirrelscan '{"url":"https://mcp.squirrelscan.com/mcp","transport":"streamable-http","auth":"oauth"}'
```

That writes this entry to `~/.openclaw/openclaw.json`:

```json
{
  "mcp": {
    "servers": {
      "squirrelscan": {
        "url": "https://mcp.squirrelscan.com/mcp",
        "transport": "streamable-http",
        "auth": "oauth"
      }
    }
  }
}
```

## 3. Log in with OAuth

```bash
openclaw mcp login squirrelscan
```

OpenClaw registers a client and prints an authorization URL. Open it in a browser and approve access. On a headless host, finish with the code from the redirect:

```bash
openclaw mcp login squirrelscan --code <code>
```

Check the setup, including a live connection:

```bash
openclaw mcp doctor squirrelscan --probe
```

<Note>The final login step has not been verified by a human yet.</Note>

## 4. Install the skills

```bash
squirrel skills install
```

That installs `audit-website` (the fix loop) and `squirrelscan` (operating the CLI). See [`squirrel skills`](/cli/skills).

## 5. Run an audit

Ask for the audit, then hand it the fixes:

```text
Audit https://nutshop.squirrelscan.com with squirrelscan and list the top issues by severity.
```

```text
Fix every core/title-missing and images/alt-missing issue, then re-audit to confirm the score went up.
```

<Note>The hosted MCP server crawls from squirrelscan's cloud, so it needs a publicly reachable URL. Use the CLI or [`squirrel mcp`](/cli/mcp) for `localhost` and private staging websites.</Note>
